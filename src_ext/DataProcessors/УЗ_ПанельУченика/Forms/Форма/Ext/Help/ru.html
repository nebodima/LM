Панель ученика

Рабочее место по одному ученику: в каких группах он занимался за период, сколько у него денег и уроков по каждой группе и список всех его уроков. Отсюда можно разом убрать ученика из уроков группы, добавить его в уроки группы или перенести его деньги с одного предмета на другой.

Как пользоваться

  1. Выберите «Ученик» и период в поле под надписью «Активные группы обучения ученика за выбранный период». В таблицу попадут группы, по которым у ученика были проведённые уроки или списания за этот период, а также уроки, куда он записан без проведения (будущие); если период не задан — за всё время. Ученик и период запоминаются до следующего открытия панели.
  2. Проверьте «Организация» (поле видно, если в программе есть организации; по умолчанию — из настроек, выбор запоминается). Деньги учеников учитываются раздельно по организациям: «Остаток денег» показывается в этой организации, новые уроки и перемещения денег записываются в неё.
  3. Посмотрите колонки «Группа обучения», «Остаток денег» и «Осталось уроков» (подробнее — ниже).
  4. В колонке «Действие» выберите, что сделать со строкой. После выбора действия колонка «Период» заполняется датами занятий по расписанию группы (дни недели и время начала дня) в пределах выбранного периода, а если он не задан — текущего месяца; для «Продлить группу» — следующего месяца. «Уроков» — сколько получилось дат. Щелчок по колонке «Период» открывает календарь: там даты можно поправить, время начала урока подставится по расписанию группы.
  5. Отметьте строку флажком в первой колонке. Флажок ставится и сам, когда меняете любую другую ячейку строки. Выполняются только отмеченные строки.
  6. Нажмите «Выполнить выбранные действия». Ход работы и результат появляются в таблице внизу окна; двойной щелчок по документу в ней открывает его. После выполнения список уроков обновляется.

Колонки таблицы групп

  • «Остаток денег» — остаток денег ученика по предмету этой группы в организации панели: с плюсом, зелёным — оплачено вперёд, с минусом, красным — долг. Двойной щелчок по сумме открывает отчёт «Взаиморасчеты» по ученику и предмету.
  • «Осталось уроков» — по действующему на сегодня абонементу ученика на предмет группы: сколько занятий осталось, тем же текстом, что в карточке абонемента (например, 6 из 8 зан.; для абонемента в часах — часы). Если абонемент сейчас приостановлен — до какой даты; если занятия в нём кончились — что он исчерпан. Без абонемента — примерно сколько уроков покрывает остаток денег по цене тарифа группы (со знаком ≈).
  • «Скидка» — скидка, которая ставится ученику во всех уроках, куда он добавляется. Отдельного правила «каждый 9-й урок со скидкой» нет: скидки — только через справочник скидок.
  • «В группу» — появляется для действия «Перевести из группы»: группа, куда переводится ученик.
  • Группа колонок «Перемещение денег» — «Из предмета», «В предмет», «Сумма» — заполняется только для действия «Перемещение денег».
  • Строку можно добавить вручную кнопкой над таблицей и выбрать в ней группу.

Действия

  • «Удалить из группы» — ищет уроки этой группы на даты из колонки «Период» (в то же время), где есть ученик, — и проведённые, и записанные без проведения. Если в уроке есть и другие ученики, ученик убирается из урока: проведённый урок проводится заново, записанный — записывается; если ученик в уроке один, урок помечается на удаление.
  • «Добавить в группу» и «Продлить группу» — добавляют ученика в урок группы на каждую дату (проведённый или записанный без проведения); если урока на дату нет, создают новый урок группы с этим учеником (педагог, предмет, помещение — по группе, длительность — по расписанию группы в этот день). Урок, который ещё не начался, только записывается без проведения — провести урок раньше его начала нельзя; прошедший урок проводится (записанный ранее без проведения — остаётся записанным). Тариф — тариф ученика, иначе тариф группы, иначе из последнего урока ученика в этой группе; абонемент — действующий на дату урока (в результате он назван; если абонемент исчерпан или приостановлен — урок по тарифу с предупреждением). Если ученик уже есть в уроке, урок не меняется; если на одну дату найдено несколько уроков группы, дата пропускается.
  • «Перевести из группы» — убирает ученика из уроков этой группы на даты из колонки «Период» (как «Удалить из группы») и добавляет в уроки группы из колонки «В группу» по её расписанию за те же дни (как «Добавить в группу»); в карточке ученика строка прежней группы закрывается днём перед первой датой перевода, строка новой группы открывается с этой даты. Перевод выполняется целиком или никак: если хоть один урок записать не удалось (нет цены тарифа, пересечение, закрытый период), прежние уроки и карточка ученика не меняются, а в результате указана причина. То, что ученик уже есть в уроке новой группы, отказом не считается.
  • «Перемещение денег» — создаёт документ «Перемещения денег» текущей датой и проводит его: сумма уменьшает остаток ученика по предмету из «Из предмета» и увеличивает по предмету из «В предмет». Касса не меняется. Перемещение записывается в организации панели. Документ не проведётся, если сумма не указана или остаток ученика по исходному предмету в этой организации меньше суммы. Группа и даты для этого действия не нужны; «Из предмета» и «В предмет» должны быть разными, сумма — больше нуля.

Что важно

  • Строка без группы, без дат или без выбранного действия пропускается — в таблице результатов появится сообщение об этом. Если ни одна строка не отмечена, панель тоже об этом сообщит.
  • По каждому уроку в таблице результатов — что с ним стало: «Проведено», «Записан без проведения (план)» или «Не записан» с причиной (пересечение, закрытый период, нет цены тарифа…). Двойной щелчок по уроку открывает его.
  • «Обновить» заново заполняет таблицу групп и список уроков; выбранные действия и даты при этом сбрасываются.
  • «Список уроков» — все уроки ученика (не только за выбранный период), сгруппированные по предмету и группе, с колонками «Дата», «Кол. часов», «Сумма итог», «Комментарий». Двойной щелчок открывает урок.
