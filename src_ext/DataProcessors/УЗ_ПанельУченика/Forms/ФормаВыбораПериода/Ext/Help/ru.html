Выбор периода

Окно панели ученика для выбора конкретных дней занятий по строке группы. При открытии в календаре отмечены дни, уже подобранные в этой строке.

  • Календарь «Выберите дни зажав Ctrl + левая кнопка мыши» — отмечайте дни щелчком с нажатой клавишей Ctrl, чтобы выделить сразу несколько.
  • «Группа обучения» — подставляется из строки панели. Если выбрать другую группу, отметки в календаре заменятся днями занятий этой группы по её расписанию. Пустая группа отметки не меняет.
  • «Заполнить даты из группы обучения» — заново отметить дни по расписанию выбранной группы (в пределах периода панели, с временем начала занятий группы).
  • «Выбрать» — закрыть окно и передать отмеченные дни в панель ученика.
