Выбор web цвета

Палитра, в которой выбирают цвет предмета, помещения или физ. лица. Открывается из карточки по кнопке выбора цвета.

  • Каждый цвет — отдельная кнопка, окрашенная в этот цвет, с его названием; полное название видно во всплывающей подсказке. Палитра прокручивается вниз.
  • Щёлкните по нужному цвету — палитра закроется, а цвет появится в карточке. Карточку после этого нужно записать.
  • Если закрыть палитру, ничего не выбрав, цвет в карточке не изменится.
