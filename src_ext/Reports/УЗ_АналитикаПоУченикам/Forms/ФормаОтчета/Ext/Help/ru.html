Аналитика по ученикам

Отчёт показывает по каждому предмету, сколько было учеников, уроков и часов, на какую сумму проведено уроков и сколько оплачено. Три таблицы: все ученики за прошлое время (до начала выбранного периода), новые ученики в выбранном периоде и все ученики в выбранном периоде.

Как сформировать

  1. «Период». Пустой период — текущий месяц. Без даты окончания отчёт строится до конца месяца начала; начало раньше 02.01.2000 заменяется на 02.01.2000.
  2. «Кассы» — при необходимости. Отбор по кассам действует только на колонку «Оплаты − возвраты».
  3. «Включать бесплатные уроки» — без флажка учитываются только уроки с суммой больше нуля.
  4. Нажмите «Сформировать».

Как читать

  • Колонки: «Предмет обучения», «Кол. учеников», «Кол. уроков», «Кол. часов», «Сумма» — стоимость уроков, «Оплаты − возвраты» — деньги учеников по этому предмету: приходы денег «Касса ученики» минус возвраты (расходы «Касса ученики»), без бонусов и без внутренней кассы. Внизу каждой таблицы — «ИТОГО». Предмет, по которому в периоде есть оплаты, но нет уроков (например, аванс за следующий месяц), тоже выводится строкой — с нулями уроков и сумм и его оплатами: итог «Оплаты − возвраты» совпадает с кассой.
  • «Кол. уроков» и «Кол. часов» — про студию: урок группы считается одним уроком, его часы — один раз (не по числу учеников); урок, на который никто не пришёл, не проведён — его нет ни в уроках, ни в часах, но его сумма (неявки «К оплате») остаётся в «Сумма». Часы — с двумя знаками. Расшифровка ячейки показывает строки учеников, а колонку «Часы урока» — один раз на урок (у первой строки проведённого урока), поэтому итог расшифровки равен ячейке.
  • «Кол. учеников» в «ИТОГО» — разные ученики: ученик, который учится двум предметам, считается один раз (в строках предметов — в каждом).
  • Новый ученик — тот, у кого по этому предмету не было уроков до начала выбранного периода.
  • Двойной щелчок по цифре открывает отдельное окно с расшифровкой: список уроков или оплат, из которых она сложилась.
