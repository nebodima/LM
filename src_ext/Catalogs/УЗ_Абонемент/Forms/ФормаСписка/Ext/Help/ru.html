Абонементы

Список абонементов всех учеников с деньгами по каждому. Из карточки ученика он открывается командой «Абонементы» — тогда в нём только абонементы этого ученика.

  • Колонки: «Код», «Наименование», «Ученик», «Действует с», «по», «Активный», «Активирован».
  • «Оплачено» — сколько оплачено по абонементу, «Израсходовано» — стоимость уже списанных уроков, «Остаток» — разница.
  • «Создать» — новый абонемент, «Создать группу» — папка для абонементов, «Скопировать» — новый абонемент по образцу выбранного.
  • «Создать на основании» — оформить оплату выбранного абонемента документом «Приход денег (ПКО)».
