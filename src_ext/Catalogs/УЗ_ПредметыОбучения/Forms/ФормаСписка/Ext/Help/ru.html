Предметы обучения

Список направлений, которым учит студия: рисование, английский, вокал и т. п. Предмет указывают в группах, уроках, абонементах и оплатах; по предметам ведётся остаток денег каждого ученика.

  • Колонки: «Наименование», «Код», «Цвет» (цвет предмета в календаре и в форме урока), «Комментарий».
  • «Создать» открывает новую карточку предмета, «Скопировать» — новую карточку по образцу выделенной строки.
  • Предметы можно разложить по группам (папкам): для этого на панели есть отдельная кнопка создания группы.
  • Двойной щелчок по строке открывает карточку предмета.
