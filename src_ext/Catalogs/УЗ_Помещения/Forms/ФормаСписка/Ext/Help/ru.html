Помещения

Список классов и залов студии. Помещение указывают в группе и в уроке; программа следит, чтобы в одном помещении не шли одновременно два урока.

  • Колонки: «Наименование», «Код», «Цвет для отображения», «Не контролировать пересечения», «Комментарий».
  • «Создать» открывает новую карточку помещения, «Скопировать» — новую карточку по образцу выделенной строки.
  • Помещения можно разложить по группам (папкам) — отдельной кнопкой на панели.
  • Двойной щелчок по строке открывает карточку помещения.
