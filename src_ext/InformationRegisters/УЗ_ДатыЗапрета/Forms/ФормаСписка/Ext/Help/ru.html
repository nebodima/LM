Даты запрета изменения

Здесь закрывают прошлые периоды, чтобы никто случайно не изменил уже сверенные уроки, оплаты и зарплату. Запрет действует на все документы учёта занятий.

  • «Пользователь» — для кого правило. Пустое значение — для всех. Строка конкретного пользователя важнее общей: так, например, администратор может снять или сдвинуть запрет для себя.
  • «Дата запрета» — документы с этой датой и раньше (включительно) нельзя записать, провести, отменить проведение, пометить на удаление или удалить.
  • «Запрет старше, дней» — скользящая граница от сегодняшнего дня: менять можно документы за сегодня и за указанное число предыдущих дней (7 — только за последнюю неделю). 0 — не действует. На пользователей с правами администратора эта граница не распространяется.
  • Если в строке заданы обе границы, действует более поздняя.
  • «Создать» добавляет правило, «Изменить» открывает выделенное.

Как это выглядит в работе

  • Документ из закрытого периода открывается только для просмотра, над формой красной строкой написана причина. При попытке записать его появляется сообщение с датой документа и датой запрета.
  • Перенести документ из закрытого периода на открытую дату тоже нельзя: проверяется и прежняя дата документа.
  • Для пользователя со скользящей границей кассовый журнал и отчёт «Ведомость по кассе для менеджеров» показывают только разрешённый период.
  • Общая строка (без пользователя) задаёт и границу, старше которой менеджер не видит кассовые документы вовсе. Она пересчитывается сразу при записи строки — не нужно ждать следующего входа или ночного обновления. Менеджер сам эту границу изменить не может.
