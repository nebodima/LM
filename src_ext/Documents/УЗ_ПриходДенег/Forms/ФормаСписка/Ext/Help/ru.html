Приходы денег

Список всех поступлений денег в кассу: оплаты учеников и прочие приходы. Двойной щелчок открывает документ.

  • Колонки: «Дата», «Номер», «Ученик», «Сумма», «Предмет», «Вид операции», «Касса», «Комментарий». Колонки «Абонемент», «Тариф», «Статья движения денег», «Организация», «Подразделение», «Автор» скрыты — их можно включить в настройке формы.
  • «Создать» — новый приход; «Скопировать» — новый приход по образцу выбранного (абонемент, дисконтная карта, автор и комментарий не копируются).
  • «Печать» → «Приходный кассовый ордер (КО-1)» — печать ордера по выбранному документу.
  • «Напомнить» — создать напоминание по выбранному документу.
  • Для поиска используйте строку поиска над списком.
