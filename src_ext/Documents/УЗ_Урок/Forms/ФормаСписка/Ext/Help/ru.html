Уроки

Журнал всех уроков. Непроведённые (запланированные) и помеченные на удаление уроки показаны серым текстом. Под списком — ученики выбранного урока.

  • Отборы. «Отбор по ученику» оставляет уроки, в которых есть этот ученик, поле «Абонемент» — уроки, где выбран этот абонемент. Действует один из двух отборов: выбор ученика очищает абонемент и наоборот. «Период» задаёт интервал дат списка.
  • Создание. «Создать урок» — новый урок; «Скопировать» — копия текущего (переносятся ученики с тарифами и дисконтными картами; скидки, абонементы, отметки, начисления и расходы не переносятся); «Помощник создания уроков» — уроки сразу на несколько дат.
  • Колонки. «Дата» с днём недели (например, Пн 21.09 18:30), «№» (номер без ведущих нулей), «Длительность» (часы и минуты, «1:30»), «Группа, предмет» (группа и предмет урока одной колонкой; предмет не повторяется, если он уже в названии группы), «Педагог», «Помещение», «Явки» (пришло / записано учеников, «4/5»), «Сумма» (итог по ученикам). Через Ещё → Изменить форму можно показать «До» (время окончания), «Статус», отдельные «Группа» и «Предмет», «Тариф», «начало», «День», «Автор», «Комментарий». Двойной щелчок по педагогу открывает его карточку, по другим колонкам — урок.
  • Ученики урока. Под списком для текущего урока видны его ученики: отметки «Явка» и «К оплате», «Ученик», абонемент, «Итого» и «Остаток по предмету» (как в форме урока: остаток денег ученика по предмету урока в организации урока; плюс — оплачено вперёд, зелёным со знаком «+», минус — долг, красным). Тариф, цена, скидка и комментарий скрыты — их можно показать через Ещё → Изменить форму.Щелчок по ученику или абонементу открывает карточку, по долгу — отчёт «Взаиморасчеты» по ученику и предмету; в контекстном меню есть «Взаиморасчеты по ФизЛицу». Отметка «Не отображать детализацию урока» прячет эту таблицу.
  • Дополнительно на экране. «Отображать диаграмму задолженности» — диаграмма долгов учеников по организациям (аванс в одной организации не гасит долг в другой; если организаций несколько, в подписи — «ученик (организация)»; педагоги не показываются) — то же правило, что у оповещений о долге; «Отображать ближайшие дни рождения» — список тех, у кого день рождения в ближайшие 10 дней, с колонкой «Исполнится» (сколько лет исполнится в этот день; выбывшие не показываются).
  • Отчёты и обработки. Ссылка «Взаиморасчеты» открывает этот отчёт (по ученику из отбора, если он выбран). В подменю «Дополнительно» — «Взаиморасчеты», «Календарь», «Явки» и «Изменение уроков». «Напомнить» — напоминание о текущем уроке.
  • При первом открытии списка программа подготавливает свои данные; если это не удалось, она выводит сообщение с причиной.
