Уроки

Журнал всех уроков. Непроведённые (запланированные) и помеченные на удаление уроки показаны серым текстом. Под списком — ученики выбранного урока.

  • Отборы. «Отбор по ученику» оставляет уроки, в которых есть этот ученик, поле «Абонемент» — уроки, где выбран этот абонемент. Действует один из двух отборов: выбор ученика очищает абонемент и наоборот. «Период» задаёт интервал дат списка.
  • Создание. «Создать урок» — новый урок; «Скопировать» — копия текущего (переносятся ученики с тарифами и дисконтными картами; скидки, абонементы, отметки, начисления и расходы не переносятся); «Помощник создания уроков» — уроки сразу на несколько дат.
  • Колонки. «№», «Дата», «До», «Часов», «Статус», «Группа», «Предмет», «Тариф», «Педагог», «Помещение», «Сумма» (итог по ученикам). Через настройку списка можно показать «начало», «День», «Автор», «Комментарий». Двойной щелчок по педагогу открывает его карточку, по другим колонкам — урок.
  • Ученики урока. Под списком для текущего урока видны его ученики: отметки «К оплате» и «Явка», «Долг по предмету» (плюс — переплата, минус — долг), абонемент, тариф, цена, скидка, «Сумма итого». Щелчок по ученику или абонементу открывает карточку, по долгу — отчёт «Взаиморасчеты» по ученику и предмету; в контекстном меню есть «Взаиморасчеты по ФизЛицу». Отметка «Не отображать детализацию урока» прячет эту таблицу.
  • Дополнительно на экране. «Отображать диаграмму задолженности» — диаграмма долгов учеников; «Отображать ближайшие дни рождения» — список тех, у кого день рождения в ближайшие 10 дней.
  • Отчёты и обработки. Ссылка «Взаиморасчеты» открывает этот отчёт (по ученику из отбора, если он выбран). В подменю «Дополнительно» — «Взаиморасчеты», «Календарь», «Явки» и «Изменение уроков». «Напомнить» — напоминание о текущем уроке.
  • При первом открытии списка программа подготавливает свои данные; если это не удалось, она выводит сообщение с причиной.
