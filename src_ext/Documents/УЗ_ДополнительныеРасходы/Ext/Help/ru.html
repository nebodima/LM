Доп. расходы

Документ учёта дополнительных расходов студии. В нём перечисляются статьи затрат и суммы; при проведении каждая строка записывается как расход по своей статье. Эти расходы собирает отчёт «Расходы» — вместе с расходами, указанными прямо в уроках, и прочими расходами из кассы (расход денег «Прочий расход»).

Один расход вводится один раз. Материалы урока — либо строками на вкладке «Доп. расходы» самого урока, либо этим документом на основании урока, не обоими способами. Расход, оплаченный наличными из кассы, — расходом денег «Прочий расход» (он сам попадает в отчёт «Расходы»); этим документом — расход без выдачи денег из кассы.

Что меняется в учёте

  • Меняется только учёт расходов по статьям затрат и организации.
  • Деньги в кассе, оплаты учеников, часы и зарплата педагогов не меняются.
  • Сумма документа при записи пересчитывается как итог по строкам.

Как пользоваться

  • Документ по уроку создают из урока: «Создать на основании» — заполнятся «Документ основания» и организация урока. Документы по уроку видны в уроке в «Связанных документах».
  • Организация документа без урока подставляется из настроек программы («Организация по умолчанию»).

Какие правила проверяются

  • В каждой строке нужны статья затрат и сумма больше нуля; документ без строк не проводится.
  • Документ по уроку, у которого расходы уже введены в самом уроке, не проводится. И наоборот: урок с расходами не проводится, пока по нему проведён этот документ.
  • Документы в закрытом периоде (даты запрета изменения) нельзя изменить, провести повторно или удалить.
