Начисления педагогам

Документ для разовых начислений педагогу, которые не считаются уроками: сумма вводится вручную с пояснением. Обычные начисления за уроки программа делает сама при проведении урока по ставке педагога.

Как пользоваться

  1. Создайте документ, выберите педагога и дату.
  2. Добавьте строки с комментарием и суммой.
  3. Проведите документ.

Что меняет в учёте

  • Каждая строка увеличивает долг педагогу на свою сумму на дату документа.
  • Начисление попадает в расчёт зарплаты, период которого включает дату документа, и выплачивается по этому расчёту. В другой проведённый расчёт то же начисление уже не попадёт.
  • «Сумма документа» — итог строк, пересчитывается при записи.
  • Документ с датой в закрытом периоде открывается только для просмотра и не изменяется.
