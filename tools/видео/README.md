## Грабли записи (29.09.2026)

- Размер окна и масштаб — ключами запуска Chrome (`--window-size=1536,864 --force-device-scale-factor=1.25`),
  не `Emulation.setDeviceMetricsOverride`: подмена снимается при отключении от браузера, это «изменение размера
  окна», и веб-клиент отменяет ввод строки таблицы.
- Ввод в ячейку таблицы — только когда поле ячейки в редактировании (`document.activeElement.id` = `formN_<Поле>_i0`),
  иначе буквы уходят в поиск по списку и открывается окно «Найти». После набора ждать ~1 с перед Tab — иначе
  значение строки теряется.
- Поиск по тексту исключает всплывающие подсказки (`.tooltip`) с тем же текстом и проверяет попадание
  (`elementFromPoint`) — иначе щелчок уходит на соседний пункт.
- Флажок в таблице меняется щелчком по самому квадратику (`.checkbox`), а не по ячейке.
- Безопасный режим расширения на копии снимать отдельным COM-соединением после заведения пользователей:
  в том же сеансе пользователь ИБ записывался без ролей («В данный момент вход в приложение невозможен»).
- Роли пользователя педагога стирает УНФ при входе администратора (управление доступом приводит роли к группам
  доступа, педагог в них не состоит) → «Нет прав на запуск требуемого вида клиента». Роли — `--роли-педагога`
  прямо перед проходом «педагог».
- Каждый веб-сеанс держит лицензию 1С, закрытая вкладка сеанс сразу не завершает — после записи `--стоп`.
