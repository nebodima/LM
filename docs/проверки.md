# Опись проверок «Учёта занятий» (УЗ_ext)

Опись сверяет сам аудит `скрипты` (`tools/аудиты/скрипты.py`): каждый аудит и каждый COM-тест
на диске обязан быть назван здесь, каждый путь `tools/…/*.py` в `docs/*.md` — существовать.
Добавил проверку — допиши строку сюда, иначе все_аудиты покраснеет.

## Как запускать

    python tools/аудиты/все_аудиты.py              # все офлайн-аудиты src_ext, бюджет ≤ 5 с (печатается)
    python tools/аудиты/самотест.py                # каждая проверка обязана краснеть: мутации на фикстурах
    python tools/прогон.py                         # COM-тесты tools/тесты/тест_*.py на УНФ, БП, УТ
    python tools/прогон.py --база=C:\1c_bases\UZ_UNF_B --пользователь=Администратор --тест=аудит_данных

Самотест: чистые фикстуры (`tools/аудиты/фикстуры`) — 0 замечаний во всех аудитах; в копию подкладывается
ровно одна ошибка — нужный аудит даёт ровно одно замечание; «почти ошибки» — ни одного. Аудит без мутации
самотест считает провалом.

## Офлайн-аудиты исходников (tools/аудиты, запускатель все_аудиты.py)

| Аудит | Что ловит |
|---|---|
| ноль_бсп | обращения к объектам БСП вне слоя УЗ_Среда (код, XML, запросы, заимствования) |
| зарезервированные_слова | `Для И =`, `Перем Метаданные`, `КАК В` — модуль не компилируется / запрос падает |
| имена | свои объекты без префикса УЗ_, остатки LM_, латиница внутри кириллических имён |
| форм_id | дубли id и имён элементов в Form.xml, битый XML формы |
| модальность | Вопрос(), ОткрытьМодально(), синхронные диалоги — в веб-клиенте падают |
| ссылки_на_метаданные | Справочники.X, таблицы и поля запросов, ЗНАЧЕНИЕ(…) — на то, чего нет |
| свойства_формы | переменная с именем свойства формы (`Доступность = …`) |
| вложенность_форм | таблица в таблице, страница вне набора страниц — клиент падает с ошибкой XDTO |
| дерево_форм | элемент лежит прямо в группе, а не в `<ChildItems>` — платформа его выбрасывает |
| дубли_формы | два поля ввода на один реквизит, одна команда двумя кнопками, пустые группы, поле без данных |
| иконки | кнопка своей команды без картинки, картинка без Representation, голая вкладка среди одетых, общая команда/подсистема без картинки, HeaderPicture вне таблицы, битая ссылка CommonPicture.УЗ_ |
| компоновка_форм | надпись вместо подписи, цвет числом, таблица короче 7 строк, ширина у ссылки, высота без предела, две командные панели, ряд шире 1280 px |
| обработчики | событие указывает на несуществующую процедуру; процедура события формы или ПОЛЯ написана и не подключена; два блока Events; чужой обработчик при своём |
| печать | параметр табличного макета, который никто не заполняет; параметр на текстовом формате; макет, который никто не получает |
| повторы_тегов | одно свойство дважды в XML — платформа молча берёт последнее |
| скрипты | эта опись: диск ↔ АУДИТЫ ↔ docs/проверки.md, тесты запускаемы, пути в docs живые, докстроки, компиляция |
| честность_проверок | немой тест, проглоченная ошибка, `проверить(True)`, проверки под «если нашлись» без else; две копии логики в форме и модуле объекта |
| чужие_коллекции | ЦветаСтиля/ШрифтыСтиля/БиблиотекаКартинок.X, где X — элемент конфигурации хозяина (по выгрузкам хозяев) |
| элементы_форм | `Элементы.X` в модуле формы, а элемента X на форме нет |
| начальная_страница | расширение объявляет или пишет начальную страницу хозяина |
| автозаполнение | пустой обработчик ПриИзменении; подстановка только в пустое поле без вопроса |
| bom | .bsl/.xml без метки UTF-8 |
| вёрстка_панелей | надписи, группы, поля внутри командной панели — веб-клиент рвёт соединение |
| форматы_чисел | «ЧГ=3 0» (не разбирается), формат в HTML без «ЧН=» |
| сетка_форм | в вертикальной группе поля начинаются вразнобой (> 26 px) |
| ширина_заголовков | заголовок колонки-флажка шире её Width, значок в шапке флажка |
| комментарий_последним | «Комментарий» не последний реквизит объекта / элемент группы формы |
| малые_иконки | своя картинка режется по краю, мелкая, пустая или сплошное пятно |
| права_роли | у своего объекта нет рабочего набора прав в УЗ_ОсновнаяРоль; права у секрета УЗ_НастройкиПочты; InteractiveDelete |
| совместимость_метаданных | с эталона выпуска (`tools/аудиты/эталон_метаданных.json`) удалён/переименован объект или реквизит, сменён тип — без записи о миграции; `--принять` при выпуске |
| сверка_хозяев | заимствованные объекты, поля Организаций/Пользователей в запросах и ЗначениеРеквизита, методы БСП из УЗ_Среда — есть в выгрузках УНФ 3.0.12, БП, УТ 11.5 |

## COM-тесты (tools/тесты, запускатель прогон.py, формат сеанс.py)

| Тест | Что проверяет |
|---|---|
| тест_аудит_данных | инварианты данных: проведённый документ имеет движения; регистратор движений жив и проведён; нет ссылок на удалённые объекты в регистрах, документах, справочниках УЗ (самопроверка в транзакции с откатом) |
| тест_блокировки | в проведении перемещения денег и расчёта зарплаты чтение остатков идёт после БлокировкаДанных на читаемый регистр; РКО, списание остатков, начисление бонусов остатков не читают (разбор модулей src_ext: на файловой базе гонку сеансов не воспроизвести) |
| тест_возврат_рко | РКО на основании карточки ученика («Касса ученики») проводится: расход кассы и баланса ученика, часы не списываются; возврат по уроку — только деньги, часы второй раз не списываются (В5) |
| тест_выплата_зарплаты | виды расхода (В7, В9): «Выплата зарплаты» на педагога гасит долг, «Прочий расход» — нет, «Внутренняя касса» в новом РКО — отказ; РКО на основании расчёта — остаток к выплате, переплата — отказ; обновление данных шаг 2 разносит старые РКО «Внутренняя касса» |
| тест_волна1_интерфейс | абонемент: наименование «ФИО с дд.мм.гг» само (30 символов, уникально, « (2)»), пустое — заполняется при проверке заполнения, уроки и цена из тарифа; В10 для помощника и календаря (УЗ_Общий.ЗаписатьУрок): будущий урок в режиме «проводить» записан без проведения с пометкой, отказ проведения — причиной; настройки — одна запись |
| тест_даты_запрета | запрет изменения по датам (УЗ_ДатыЗапрета) |
| тест_изменение_уроков | обработка «Изменение уроков»: отметки явки/оплаты перепроводят урок (документ и регистр согласованы), без изменений — без записи, закрытый период — отказ с причиной |
| тест_кассы | основная касса (реквизит «Основная», иначе предопределённая), остаток кассы по всем клиентам, «Переместить деньги» из расчёта зарплаты |
| тест_обновление | обработчики обновления данных (УЗ_ОбновлениеДанных, УЗ_ВерсииДанных) |
| тест_оповещения | напоминания и оповещения (УЗ_Оповещения) |
| тест_остатки_по_строкам | виртуальная таблица Остатки сворачивает неиспользуемые измерения (одна строка); перемещение между предметами — контроль по сумме остатка |
| тест_отчеты | все отчёты на СКД формируются, поля с заголовками |
| тест_печать | ПКО/РКО и начисление бонусов: своя печать и через БСП хозяина |
| тест_права | живой сеанс сотрудника с УЗ_ОсновнаяРоль: всё нужное можно, секреты нельзя |
| тест_приход_бонусы | ПКО: списание бонусов карты — пустая/недостаточная карта отказ; срок карты одинаков с уроком (по день окончания включительно, с даты начала, «Не действует») |
| тест_расчет_зарплаты | расчёт зарплаты: строго период документа, без начислений из других проведённых расчётов (и отказ при повторе), сумма = итог таблицы, копия без РКО, дата запрета по дате движений |
| тест_сквозной | деньги целиком: абонемент → ПКО → уроки (явка, неявка «К оплате») → остатки учеников, кассы, абонемента → начисление педагогам → РКО и расчёт зарплаты → отмена проведения и перепроведение (движения те же) → уборка без хвостов; всё числами по регистрам |
| тест_расчет_зарплаты | расчёт зарплаты: строго период документа, без начислений из других проведённых расчётов (и отказ при повторе), сумма = итог таблицы, копия без РКО, дата запрета по дате движений |
| тест_списание_остатков | списание остатков: часы в регистр — секунды, колонка часов дробная |
| тест_урок | цена тарифа при проведении урока, новый педагог в группе «Педагоги» |
| тест_урок_абонемент | абонемент не расходуется сверх занятий/часов (в т.ч. двумя строками одного урока), выключенный и чужой — отказ; факт: остаток не дробится по явке/педагогу |
| тест_урок_правила | решения владельца 28.09: цена урока по абонементу (В2), приостановка и продление срока (В4), начисления без явки (В6), смена цены тарифа только после последнего урока (В8), будущий урок не проводится (В10) |
| тест_урок_пересечения | пересечение по педагогу/помещению (вложенный, накрывающий, заходящий урок) — отказ проведения с сообщением у поля; стык, пустое помещение и «Не контролировать пересечения» — проводится |
| тест_урок_цена | цена строки урока пересчитывается при смене часов, даты, тарифа; скидка — в сроке действия, от 0 до цены, 0/0 не роняет и не переносится |
| тест_фото | фото физ. лиц |

## Проверки «Путевых листов», которые не перенесены

| Проверка ПЛ | Почему нет |
|---|---|
| аудит_html_совместимости | HTML-полей с собственной вёрсткой в УЗ нет; появится HTML — перенести |
| аудит_справки, аудит_полноты_справки, аудит_подписей_справки | у УЗ_ext нет справки (Help.xml) |
| проверка_ролика | роликов у продукта нет |
| проверка_обрезки_карточек | не файловая проверка: нужен веб-стенд и headless-браузер со снимками (модуль снимки_справки ПЛ); делать вместе с веб-осмотром форм |
| аудит_автозаполнения, правило «у поля-ссылки нет ПриИзменении» | держится на реестре согласованных полей предметной области ПЛ; перенесена общая часть (пустой и половинчатый обработчик) |
| аудит_иконок, правило «кнопка записи карточки объявлена явно» | решение владельца ПЛ о виде панели, для УЗ такого решения нет |
| аудит_компоновки_форм, долг компоновка_долг.json | в УЗ долга нет — показывается всё найденное; осознанное исключение — `<!-- компоновка: Элемент причина -->` в Form.xml |
