**Следующий шаг — электронная передача сведений справки в ФНС.** С 2024 года организация по заявлению
налогоплательщика передаёт сведения справки в налоговую сама — «при наличии технической возможности», по ТКС с
усиленной квалифицированной подписью, в течение 30 календарных дней со дня заявления (порядок передачи —
приложение 4 к приказу ЕД-7-11/755@; `факты_и_источники.md`, раздел 2); переданные сведения попадают в личный
кабинет, бумажную справку человеку подавать не нужно. Это не «передача по запросу налоговой», а обязанность по
заявлению человека при технической возможности. Нужно: XML по утверждённому формату (приложение 3 к приказу —
найти и сверить), выгрузка файла из справки, сдача — через программу отчётности покупателя (1С-Отчётность, Контур
и т. п.); свою ТКС расширение не делает.

## Правила владельца, которые легко забыть

- Писать кратко, без промежуточных отчётов; решения по учёту — самому, «как в типовых».
- Проверки — на одной БП; сначала весь код, потом один деплой и один прогон.
- Без worktree; в основной папке могут работать другие сессии — коммитить только свои файлы.
- `UZ_DEMO` обновлять/копировать только когда владелец вышел из базы; `UZ_BP_C` и `C:\Apache24` не трогать.
- Codex до ~05.10.2026 не звать без просьбы владельца (лимит).
- Фитнес-клубы в описаниях не упоминать; целевые — музыкальные, математические, робототехнические школы и студии.
