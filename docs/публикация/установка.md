# «Учёт занятий»: установка и первый запуск

Инструкция для администратора базы 1С, в которую ставится расширение «Учёт занятий» 2.0.

«Учёт занятий» 2.0 — новая версия продукта «Учёт уроков». Она ставится на чистые данные: перенос из прежней
конфигурации «Учёт уроков» (УчетУроков) не предусмотрен.

## 1. Что нужно

| | |
|---|---|
| Платформа | 1С:Предприятие 8.3.24 или новее (режим совместимости расширения — 8.3.24). Проверено на 8.3.27. |
| Конфигурация | **не базовая версия** (в базовые версии расширения не устанавливаются): 1С:Управление нашей фирмой 3.0, 1С:Бухгалтерия предприятия 3.0, 1С:Управление торговлей 11.5 или 11.6, 1С:Комплексная автоматизация 2.5, 1С:ERP Управление предприятием 2.5 и отраслевые решения на её основе |
| Режим совместимости конфигурации | **не ниже 8.3.24.** Расширение использует предопределённые элементы, определяемые типы и критерии отбора, а платформа допускает их в расширении только в режиме совместимости 8.3.15 и выше. **УТ 11.4 (режим совместимости 8.3.14) не поддерживается** — обновитесь до 1С:Управления торговлей 11.5 |
| Клиент | тонкий клиент или веб-клиент |
| Права того, кто устанавливает | «Полные права» (администратор) |

На каких релизах проверено:

| Конфигурация | Работа проверена на копиях баз (тесты, вход сотрудников) | Метаданные сверены по выгрузке |
|---|---|---|
| Управление нашей фирмой 3.0 | 3.0.12 | 3.0.12.261 |
| Бухгалтерия предприятия 3.0 | 3.0.174 | 3.0.196.21 |
| Управление торговлей 11.5 | 11.5.25 | 11.5.26.110 |
| Управление торговлей 11.6 | 11.6.1.70 | 11.6.1.70 |
| ERP Управление строительной организацией 2.5 | 2.5.21.111 (тесты; вход сотрудников в веб-клиент не проверялся) | 2.5.21.111 |

Комплексная автоматизация 2.5 устроена как Управление торговлей 11 и ERP 2.5: кассовые документы, партнёры и роли — те же; отдельно на базе КА работа не проверялась.

Проверки шли на файловых базах. В облачном сервисе 1С:Фреш работа не заявлена.

**Перед установкой сделайте резервную копию базы.**

## 2. Установка

1. Откройте раздел **Администрирование** (в Управлении нашей фирмой — **Настройки → Администрирование**,
   в Управлении торговлей — **НСИ и администрирование → Администрирование**).
2. **Печатные формы, отчеты и обработки → Расширения**.
3. Нажмите **Добавить из файла...** и выберите файл расширения «Учёт занятий» (файл с расширением `.cfe`,
   полученный после покупки).
4. В списке появится строка **Учёт занятий** (имя в конфигураторе — `УЗ_ext`).
5. Снимите у неё флажок **Безопасный режим** (раздел 3 ниже).
6. Перезапустите программу. В панели разделов появится раздел **Учёт занятий** с подразделами «Занятия»,
   «Касса», «Справочники», «Отчеты», «Настройки».

Конфигурацию снимать с поддержки не нужно, обновления типовой ставятся как обычно.

## 3. Безопасный режим: снять и почему

Расширение, загруженное из файла, 1С включает в безопасном режиме. В нём не работают две вещи, без
которых «Учёт занятий» не обходится:

* **подготовка данных при первом запуске и после обновления** — она записывает общие настройки, кассы и
  документы в привилегированном режиме, а в безопасном режиме он запрещён;
* **отправка почты** (письма ученикам о задолженности, проверочное письмо) — в безопасном режиме интернет-почта
  запрещена.

Если режим не снять, при открытии журнала уроков программа сообщит: «Учёт занятий не смог подготовить свои
данные. У расширения «Учёт занятий» включён безопасный режим…», а форма «Настройки почты» покажет внизу, что
отправка почты в безопасном режиме запрещена.

Как снять: **Администрирование → Печатные формы, отчеты и обработки → Расширения** → выделите «Учёт занятий» →
снимите флажок **Безопасный режим** → перезапустите программу.

Что это значит для безопасности: без безопасного режима код расширения работает с теми же возможностями,
что и код самой конфигурации. Код «Учёта занятий» открыт — его можно прочитать в конфигураторе.

## 4. Доступ сотрудникам

В «Учёте занятий» две роли:

* **«Учёт занятий: менеджер»** — администратор студии на ресепшене: уроки, ученики, абонементы, приём денег,
  возврат денег ученику, календарь, отчёты по урокам и явкам. Зарплату педагогов, ставки, расходы, настройки
  и даты запрета он не видит и не меняет (настройки и даты запрета — только просмотр).
* **«Учёт занятий: руководитель»** — всё, включая зарплату педагогов, расходы, настройки, даты запрета и все отчёты.

Настройки почты меняет только администратор с «Полными правами». Ему роли «Учёта занятий» не нужны.

### Способ 1 — сотрудник уже работает в программе

1. **Администрирование → Настройки пользователей и прав → Профили групп доступа**.
2. Откройте профиль сотрудника. Если роли профиля изменить нельзя (профиль поставляемый) — нажмите
   **Скопировать**, назовите копию, например «Продажи и учёт занятий», и дальше работайте с копией.
3. На закладке **Разрешенные действия** отметьте **«Учёт занятий: менеджер»** (руководителю —
   **«Учёт занятий: руководитель»**). Нажмите **Записать и закрыть**.
4. Если делали копию — в **Группы доступа** переключите группу сотрудника на новый профиль.

### Способ 2 — отдельные профили только для «Учёта занятий»

В **Профили групп доступа** нажмите **Создать**, назовите профиль «Учёт занятий: менеджер», отметьте роли
вашей программы из таблицы и роль **«Учёт занятий: менеджер»**. Так же создайте профиль «Учёт занятий:
руководитель» — те же роли программы и роль **«Учёт занятий: руководитель»**.

| Программа | Роли программы (для обоих профилей) |
|---|---|
| Управление нашей фирмой 3.0 | Базовые права БСП; Базовые права БТС; Базовые права приложения; Запуск тонкого клиента; Запуск веб-клиента; Вывод на принтер, в файл, в буфер обмена; Сохранение данных пользователя |
| Бухгалтерия предприятия 3.0 | Базовые права БСП; Базовые права: Бухгалтерия предприятия; Базовые права по электронным документам; Базовые права Интернет-поддержки пользователей; Базовые права БТС; Просмотр организаций; Запуск тонкого клиента; Запуск веб-клиента; Вывод на принтер, в файл, в буфер обмена; Сохранение данных пользователя |
| Управление торговлей 11, КА 2.5, ERP 2.5 | Базовые права БСП; Базовые права УТ; Чтение организаций и банковских счетов организаций; Запуск тонкого клиента; Запуск веб-клиента; Вывод на принтер, в файл, в буфер обмена; Сохранение данных пользователя |

Затем **Группы доступа → Создать**: группа «Учёт занятий: менеджеры» с профилем «Учёт занятий: менеджер» и
группа «Учёт занятий: руководители» с профилем «Учёт занятий: руководитель»; на закладке **Участники**
добавьте сотрудников. **Записать и закрыть.**

Если в Управлении нашей фирмой сотрудник с таким профилем при входе получает «Недостаточно прав для работы с
таблицей РегистрСведений.КурсыВалют.СрезПоследних» — добавьте в профиль роль **«Чтение курсов валют»**.

## 5. Первый запуск

1. Войдите **администратором или руководителем** (у менеджера на это не хватит прав).
2. Откройте **Учёт занятий → Занятия → Уроки**. При первом открытии журнала уроков (или кассового журнала)
   программа подготавливает свои данные:
   * если ни одна касса не отмечена основной, отмечает так кассу **Основная касса** (она есть в программе
     с самого начала);
   * заполняет настройки: касса по умолчанию — «Основная касса», организация по умолчанию — первая
     организация базы, период оповещений — 300 секунд, срок задолженности — 2 дня;
   * записывает границу, с которой менеджеру видны кассовые документы (по общему правилу дат запрета).
   Уже заполненные настройки она не трогает.
3. Если подготовка не удалась, над журналом появится сообщение с причиной. Подробности — в журнале
   регистрации, событие «Учёт занятий.Обновление данных».

Пока подготовка не выполнена, менеджер при открытии журнала видит: «Учёт занятий ждёт подготовки своих данных
после обновления: руководителю или администратору открыть журнал уроков».

## 6. Настройки

### Организация и касса

**Учёт занятий → Настройки → Настройки** (руководитель или администратор):

* **Организация по умолчанию** — подставляется в новые уроки, приходы и расходы денег, доп. расходы,
  начисления педагогам, расчёты зарплаты, графики педагогов. Деньги учеников учитываются раздельно по
  организациям.
* **Касса по умолчанию** — подставляется в новые приходы и расходы денег и расчёты зарплаты.
* **Использовать оповещения** — ежедневная проверка долгов учеников (с 7:00): по должнику, у которого долг
  старше срока из поля **Оповещать о задолженности за … дней**, заводится общее оповещение, его видят все
  пользователи.
* **Период оповещения (секунд)** — как часто программа показывает всплывающие напоминания. Действует со
  следующего входа.
* **Использовать округление** — цена, скидка и сумма ученика в уроке округляются до целых рублей.

Свои кассы (сейф, терминал) заводятся в **Учёт занятий → Касса → Кассы**; основную назначает кнопка
**Сделать основной** в списке касс.

### Почта

**Учёт занятий → Настройки → Настройки почты** (только администратор — в форме хранится пароль ящика):

1. Отметьте **Отправлять письма**.
2. Заполните **Сервер SMTP**, **Порт** (0 — 465 при SSL и 25 без него), **Защищённое соединение (SSL)**,
   **Логин**, **Пароль**, **Адрес отправителя**, **Имя отправителя**. Параметры сервера сообщает ваш почтовый
   сервис.
3. Отметьте **Письма ученикам о задолженности**, если нужны письма должникам.
4. Нажмите **Проверить** — настройки сохранятся, на адрес отправителя уйдёт проверочное письмо, результат
   появится в строке «Состояние» внизу формы.

Письмо о задолженности уходит ученику и его ответственному родственнику, если в их карточке («Физ. лица»)
заполнен e-mail и отмечено **Оповестить по email**. Письма отправляются только при снятом безопасном режиме.

Проверку долгов выполняет регламентное задание «Проверка задолженности».

### Даты запрета

**Учёт занятий → Настройки → Даты запрета изменения** (меняет руководитель): дата, до которой (включительно)
документы нельзя изменить, или скользящая граница «Запрет старше, дней». Пустой «Пользователь» — правило
для всех.

Подробно о каждой форме — клавиша **F1** в этой форме.

## 7. Обновление на новую версию

1. Сделайте резервную копию базы.
2. **Администрирование → Печатные формы, отчеты и обработки → Расширения** → выделите **Учёт занятий** →
   **Обновить из файла...** → выберите файл новой версии.
3. Проверьте, что у «Учёта занятий» снят флажок **Безопасный режим**.
4. Перезапустите программу.
5. Первым откройте журнал уроков **под руководителем или администратором** — программа догонит свои данные
   до новой версии.

**Не удаляйте расширение и не добавляйте новую версию вторым расширением рядом.** Удаление расширения
удаляет из базы все его данные: уроки, учеников, абонементы, кассу, зарплату. Новая версия загружается
только в то же расширение — кнопкой «Обновить из файла...».
