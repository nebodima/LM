## Правила владельца (обязательны)

- **Учётные данные Инфостарта не вводить никогда.** Если площадка просит войти — просить владельца войти самому
  во встроенном браузере. Коды из SMS/почты тоже не вводить.
- **Файлы в формы загружает только владелец** (перетаскивает в поле). Не пытаться загружать скриптом, через iframe,
  postMessage и т. п. — такая попытка уже была заблокирована; не повторять. Наша часть: подсветить поле
  (розовая рамка и надпись «СЮДА: имя_файла»), прокрутить к нему и назвать полный путь к файлу.
- **Сохранение = отправка на модерацию** (для опубликованной публикации). Сохранять только по слову владельца
  («готово», «да», «сохраняй»).
- Изображение анонса (картинку карточки) не трогать. Галерейные изображения не удалять.
- В текстах: без эмодзи, без символа рубля (писать «руб.»), без названия компании и имён владельца, без
  пометок-заглушек вроде «[СВОЙ ОПЫТ]», без обещаний «гарантирует/сэкономит». Факты — только подтверждённые
  исходниками или журналом изменений; чего нет в продукте — говорить прямо, что нет.
- Демо-организация на снимках «Ассоль ООО» — вымышленная, допустима.
- Во время работы с формой **не закрывать панель браузера**: несохранённые правки пропадают целиком
  (случилось 29.09), а после закрытия площадка просит войти заново.

## Устройство формы редактирования (Bitrix)

Страница в cp1251. Всё делается `javascript_tool` во встроенном браузере (`mcp__Claude_Browser__*`).

- Описание — CKEditor: `CKEDITOR.instances.DETAIL_TEXT.getData()` / `.setData(html)`. Дождаться
  `CKEDITOR.instances.DETAIL_TEXT.status === 'ready'`. Правки — заменой точного фрагмента HTML с проверкой,
  что он встречается ровно один раз (`h.split(a).length === 2`), иначе остановиться. Кавычки в HTML — `&laquo;`/`&raquo;`,
  тире `&mdash;`.
- Заголовок `[name="FIELDS[NAME]"]`, анонс `[name="FIELDS[PREVIEW_TEXT]"]`, ключевые слова
  `[name="PROPERTIES[KEYWORDS]"]`, причина правки `[name="PROPERTIES[EDIT_REASON]"]` (заполнять).
- Товарные позиции — блоки `.js-block-file`. В блоке: `FILES[NAME][]`, `FILES[SMALL_NAME][]`, `FILES[PREVIEW_TEXT][]`,
  `FILES[PRICE][]`, `FILES[TYPE][]`, `FILES[VERSION][]`, `FILES[FID][]` (после замены файла FID меняется — искать блок
  по названию, а не по FID). Поле для файла — `.dropzone` внутри блока; после загрузки у `.dz-preview` класс `dz-success`.
- **После замены файла позиции обязательно поднять `FILES[VERSION][]`** (площадка пишет «укажите новую версию»).
- Конфигурации тестирования: `SUPPORTED_CONFIGS[n][k][CONFIG]` (select2) и `...[RELEASE]` (скрытый input, текст релиза
  виден в родителе). Замена файла может их сбросить — **до загрузки файла снять значения**
  (`[...document.querySelectorAll('[name^="SUPPORTED_CONFIGS"]')].filter(e=>e.value&&e.value!=='0')`), после — сравнить.
  У позиции 2.1 сейчас: БП 3.0 / 3.0.174.30, УНФ 3.0 / 3.0.12.261, УТ 11 / 11.5.25.112.
- Удаление позиции — ссылка `a.RemoveFile` в блоке: `jQuery(a).trigger('click')`, появится окно SmartMessageBox
  (`.divMessageBox`) — нажать кнопку «Да». Для позиции с заказами в рублях площадка требует «наследника».
- Сохранить: `button[name=ACTION][value=SAVE]`. Перед нажатием снять залипшие метки
  `document.querySelectorAll('.invalid').forEach(e=>e.classList.remove('invalid'))` — иначе клик глохнет.
  Скрытые обязательные поля: рубрика (сбрасывается при смене вида объекта), «Код открыт», картинка анонса
  (`#dropzone-detail`). После сохранения страница уходит на `?s=y&ID=…` или на карточку; проверять на публичной
  странице: «На модерации» и новый текст.
- Статья правится той же формой (`/public/edit/?id=2802677`), картинки статьи грузит владелец.

## Таблицы и код в тексте (от сессии ПЛ, 30.09.2026)

Сайт сбрасывает стили таблиц — без явных стилей таблица выглядит «не как таблица». Рецепт (проверен на статье 2803654):
- `<table class="table table-bordered" style="width:100%;border-collapse:collapse;border:1px solid #d8d2e3;margin:16px 0;">`;
- `th`: `style="border:1px solid #d8d2e3;padding:10px 12px;background:#efeaf6;text-align:left;vertical-align:top;"`;
- `td`: `style="border:1px solid #d8d2e3;padding:10px 12px;vertical-align:top;"`, через строку `background:#faf8fd`.
- Код — `<pre><code class="language-onec8">…</code></pre>` (сайт красит highlight.js; голый `<pre>` не красится).
