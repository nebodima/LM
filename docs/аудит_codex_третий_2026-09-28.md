1. РКО «Касса ученики» и перемещение между предметами проверяют предмет документа; без предмета — свободный аванс
   без предмета (`УЗ_Сервер.СвободныйАвансБезПредмета`: остаток пустого предмета минус долги предметов, в которые он
   зачитывается); перемещение без предмета в предмет с долгом — плюс долг получателя. Блокировка — деньги ученика в
   организации целиком.
2. ПКО с абонементом: «Касса ученики», ученик, организация и предмет абонемента
   (`Документы.УЗ_ПриходДенег.ТекстНесогласованногоАбонемента`); форма — отбор абонемента по ученику, очистка при
   смене организации/предмета, заполнение из выбранного абонемента.
3. `Документы.УЗ_ПриходДенег.ПроверитьИзъятиеБонусов` / `ПередЗаписьюДокументаБонусов` в «Начислении бонусов»,
   уроке и списании остатков: уменьшение, смена карты, отмена проведения — только если остаток карты после документа
   ≥ 0 (под исключительной блокировкой карты).
