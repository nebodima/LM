# Отчёты — сверка цифр

Разбор 28.09.2026, только чтение кода (`src_ext`, для сравнения — `Reports\LM_*` в корне). Пути ниже — от
`src_ext\`, если не сказано иное. Строки — по состоянию исходников на 28.09.2026.

## 1. Назначение

Владелец студии смотрит одни и те же величины в разных местах: долг/аванс ученика, сколько пришло денег,
сколько в кассе, сколько уроков и часов проведено, кто пришёл, сколько начислено педагогу, сколько бонусов на
карте. Если отчёт, карточка ученика и форма урока показывают разные числа, владелец перестаёт верить учёту.
Эта логика — сверка: откуда каждая цифра берётся, с какими отборами, и где одна и та же величина считается
по-разному.

## 4. Расхождения

**Р1. Организация (В12) — половина мест её не учитывает.** Документы, панель и форма урока считают остаток по
организации, а форма ученика, список учеников, список уроков (колонка и диаграмма), оповещение о долге и отчёт
«Взаиморасчёты» — по всем организациям сразу. Ученик с авансом 8 000 в А и долгом 1 000 в Б в форме урока Б —
«−1 000», в карточке и отчёте — «+7 000», оповещения о долге не получит. Отчёты Аналитика, Ведомость для
менеджеров, Явки, Расходы, Зарплата, Бонусы организацию не показывают вообще (в Явках и Бонусах поле объявлено
в схеме, но его нет в запросе).

**Р2. Три разных «оплаты за период».** Ведомость по кассе (все ПКО и перемещения между кассами, без бонусов),
Аналитика («Сумма оплат» — `СуммаДокумента` ПКО любого вида, без бонусов, без возвратов, только по предметам с
уроками в периоде), Взаиморасчёты («Приход» — оплаты учеников + бонусы + перемещения между предметами).
Совпадают только в простейшем случае «один ПКО „Касса ученики“ на предмет с уроками» — его и проверяет
`тест_отчеты.py`.

**Р3. Уроки: «событие» против «строки ученика».** Аналитика считает уроки разными документами (группа = 1
урок), Взаиморасчёты и форма абонемента — строками учеников (группа из 5 = 5). Часы в обоих — по строкам
учеников, то есть в Аналитике «1 урок, 5 часов» для часового урока группы. Для рок-школы (индивидуальные)
числа совпадают, для математики/робототехники — нет. Часов педагога не показывает ни один отчёт.

**Р4. Урок без единой явки (В6).** По В6 такой урок не проведён: педагогу не начислено, в «Расчётах по
зарплате» его нет. Но Аналитика и Взаиморасчёты считают его уроком и часами (неявка «К оплате» пишет урок и
часы), а его сумма пропадает из «Выручки» зарплатного отчёта.

**Р5. «Выручка» зарплатного отчёта — не выручка.** Это «сумма урока − начисление педагогу» и только по
регистраторам регистра зарплаты: уроки без начислений (В6, педагог без ставки) выпадают целиком; ручная премия
документом «Начисления педагогам» одной строкой не вычитается (`Регистратор.Сумма` у документа нет → NULL,
`Template.xml:227-236`), двумя строками — вычитается только вторая; доп. расходы урока (материалы
робототехники) не вычитаются.

**Р6. Неявки.** Строка «не пришёл, не к оплате» движений не пишет (`УЗ_Урок\Ext\ObjectModule.bsl:87-89`),
поэтому «Таблица явок» не отличает её от «не был записан»; неявка «К оплате» — «0». Для математики (журнал
посещаемости группы) это потеря информации; для рок-школы неважно.

**Р7. Бесплатные занятия.** Явка без «К оплате» пишет урок, часы и явку с суммой 0: Взаиморасчёты их считают,
Аналитика по умолчанию — нет (`СуммаРасход > 0`, `Module.bsl:21-23`), «Взаиморасчёты по преподавателям»
отсекают их отбором `СуммаОборот ≠ 0` (`Template.xml:1149-1151`) — у одного педагога в двух вариантах одного
отчёта разное число уроков и часов.

**Р8. «Новый ученик» — два определения.** Аналитика: не было часов по этому предмету до начала периода
(`Module.bsl:1365-1380`). Взаиморасчёты «только новые»: `ЧасыНачальныйОстаток = 0` на уровне записи
(Клиент × Педагог × Тариф × Группа × Абонемент…, `Template.xml:1385-1387`) — старый ученик у нового педагога
или по новому абонементу «новый».

**Р9. Возвраты и списание остатков.** Возврат РКО уменьшает «Приход» только в кассе; в Аналитике оплата
остаётся полной. Списание долга пишет Расход с минусом — во Взаиморасчётах колонка «Расход» отрицательная.
Списание не трогает абонемент: деньги и занятия абонемента остаются, и урок по нему снова проводится (С7).

**Р10. Прочий расход (В7) и отчёт «Расходы».** «Расходы» — только доп. расходы уроков и документ «Доп.
расходы»; аренда/хозрасходы РКО «Прочий расход» туда не попадают. В кассе «Выплата зарплаты» и «Прочий расход»
лежат под одним видом «Внутренняя касса» (`УЗ_РасходДенег\Ext\ObjectModule.bsl:80-88`) — кассовые отчёты их
не различают (поля ВидОперации/СтатьяЗатрат в «Ведомости по кассе» объявлены, но не выбираются запросом).
«Расходы» показывают «кон. остаток» как накопленный минус и не имеют организации.

**Р11. Касса и организация.** Контроль В14 и «Переместить деньги» — по кассе без организации, а «Ведомость по
кассе» группирует по организации: перемещение всего остатка кассы организацией расчёта даёт в отчёте минус у
этой организации (С8). Списание остатков расходует кассу без контроля В14 (`УЗ_СписаниеОстатков\Ext\ObjectModule.bsl:40-52`).

**Р12. Округления и часы (В13).** Регистр хранит целые секунды — это верно. Но Аналитика выводит часы
`Текст = число` без формата (`Module.bsl:373, 507, 641, 1087, 1201`), форма абонемента — остаток часов
строкой без формата (`Module.bsl:198-200`), панель — `ЧДЦ=2`, «Движения документа» — секунды. «% с оплаты»
педагогу считается без `Окр(…, 2)` (`УЗ_Урок\Ext\ManagerModule.bsl:69`) — округляет платформа при записи в
реквизит. Настройка «Использовать округление» округляет суммы уроков до рубля — отчёты это наследуют.

**Р13. Бонусы в форме урока.** Остаток бонусов в строке урока — по ученику и карте; ПКО тратит бонусы от имени
владельца карты — форма урока показывает больше, чем есть (С10). ПКО и форма карты считают по карте верно.

**Р14. Мелкие.** Ведомость для менеджеров не показывает кассу с остатком без движений в периоде, хотя её
остаток входит в «Итого» (`Module.bsl:90-91` против `:38-45`). Расшифровки Аналитики берут конец периода без
`КонецДня` (`Module.bsl:812, 903, 1130, 1244`), основная таблица — с ним (`:194-195`) — при ручной дате без
времени расшифровка теряет последний день. Форма ученика берёт цену тарифа из карточки, панель — из истории
цен (В8). Панель ученика не продлевает срок абонемента на приостановки (`Module.bsl:125-126`), урок —
продлевает (`УЗ_Урок\Ext\ManagerModule.bsl:262`).

**Режимы.** Рок-школа (индивидуальные, почасовые): Взаиморасчёты, Аналитика (часы), форма ученика «по
тарифу» (единицы часов), ставка «за час». Школа математики (группы, поурочно, абонементы): Явки_2, вариант
Взаиморасчётов «по гр. обучения», панель ученика («6 из 8»), форма абонемента; Аналитика для групп даёт
ученико-часы. Школа робототехники (группы, материалы, доп. расходы): только «Расходы» (без связи с группой,
уроком и выручкой). Общие: обе ведомости по кассе, бонусы, движения документа, расчёты по зарплате.
