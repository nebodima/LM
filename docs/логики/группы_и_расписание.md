## 1. Назначение

Группа — постоянное занятие: кто ведёт (педагог), что (предмет), где (помещение), почём (тариф группы) и когда
(дни недели со временем). По группе помощник и панель ученика создают уроки на месяц, календарь фильтрует уроки,
ученика переводят из группы в группу. Индивидуальное занятие — урок без группы. График рабочего времени педагога —
отдельный месячный документ: в какие дни и часы педагог работает; урок вне графика вызывает предупреждение.

## 2. Правила как есть

1. **Реквизиты группы** (`Catalogs\УЗ_ГруппыОбучения.xml`): Педагог, ПредметОбучения, Помещение, Тариф; общее
   время `Время`–`ВремяОкончания` и `Продолжительность` (тип Дата); по дням `ПН..ВС` (флажок) + `ПНВремя`/`ПНВремя2`
   … `ВСВремя`/`ВСВремя2`. Проверок заполнения у педагога/предмета/тарифа нет. Иерархия — папки.
2. **Проверка расписания при записи** (`Гр\Ext\ObjectModule.bsl:2-92`): у отмеченного дня оба времени обязательны
   и «с» ≤ «по» (равные допускаются). Сообщения через `Сообщить`, без привязки к полю.
3. **Форма группы:** снятие флажка дня очищает его время (`ГрФ:24-109`); «Установить общее время» копирует
   `Время`–`ВремяОкончания` во все отмеченные дни (`ГрФ:118-155`); изменение начала/конца пересчитывает
   `Продолжительность` (`ГрФ:197-203`), изменение длительности — конец (`ГрФ:158-164`). Время дня от
   длительности не пересчитывается.
4. **Урок — заполнение из группы** (форма урока, `Урок\Forms\ФормаДокумента\Ext\Form\Module.bsl:424-447`): педагог,
   ставка педагога, помещение, часы = `Продолжительность` (общая, не время дня недели), предмет, тариф шапки (если у
   группы задан). Время начала урока не меняется, ученики не подставляются, строки учеников не пересчитывают тариф.
5. **Урок — ограничение «только выбранные группы»** (`УО:19-21, 367-393`): при любой записи (и плана) у каждого
   ученика с флажком `ТолькоВыбранныеГруппыОбучения` группа урока должна быть в его ТЧ; дата урока ≤ конец дня
   `ДатаОкончания` (пустая — бессрочно). `ДатаНачала` не проверяется. Если строк группы несколько и хотя бы одна
   просрочена — отказ, даже если другая действует.
6. **Индивидуальный урок** (группа пустая): проверка правила 5 не выполняется, помощник требует ручное время
   (`Пом:118-123`), конфликт «группы» не проверяется (`УМ:824-826`); панель ученика такие уроки не показывает в
   таблице групп (`Пан\Forms\Форма\Ext\Form\Module.bsl:45,57`).
7. **Помощник, «Создание уроков»** (`Пом:105-146`):
   - выбор группы подставляет педагога, предмет, помещение, тариф, общее время и длительность, отмечает дни недели
     группы с **сегодня** (`ТекущаяДата()`) до конца месяца или весь следующий месяц (`Пом:424-543`);
   - ученики: сначала (при «Добавлять в существующие») — ученики с флажком «только выбранные» и этой группой в ТЧ,
     без отбора по датам и пометке удаления (`Пом:454-480`); затем при смене группы таблица **перезаполняется** всеми
     учениками с группой в ТЧ, действующей на **сегодня**, без педагогов и помеченных, с тарифом (ученика → группы),
     скидкой и действующим абонементом (`Пом:364-422`). При открытии формы и в режиме «Перевод» работает только
     первый способ;
   - время на дату — из дня недели группы (`ПолучитьВремяИзГруппы`, `Пом:7-45`) при «Заполнять из группы» и без
     ручного времени; день без флажка молча пропускается (`Пом:135-137`); длительность = `ДеньВремя2 − ДеньВремя`;
   - запись — `УМ.ЗаписатьУчениковВУрок` (`УМ:628-719`): существующий урок ищется точно (начало, группа, педагог,
     предмет, помещение, `УМ:779-807`); другой длительности — отказ; новый — не поверх урока того же педагога,
     помещения или **той же группы** в пересекающееся время, включая планы (`УМ:811-864`). В10 — будущий урок только
     записывается (`CommonModules\УЗ_Общий\Ext\Module.bsl:77-109`).
8. **Помощник, «Продление группы»** (`Пом:147-228`): ученики, тариф, скидка, «К оплате» — из **последнего** урока
   группы (любого, в т. ч. плана); время — общее `Время`/`Продолжительность` группы, не время дня; дата
   пропускается, если у группы в этот день уже есть любой урок; проверки конфликтов помощника (п. 7) нет; абонемент и
   карта не переносятся; если у группы нет ни одного урока — `Док` не определён (`Пом:171, 210`) и цикл падает вне
   `Попытка`.
9. **Помощник, «Перевод из группы» (Q03)** (`Пом:230-251`, `УМ:721-767`): даты отмечаются по дням недели группы
   **«из»** (`Пом:647-667`), время берётся из расписания группы **«в»**; день, которого нет у новой группы, молча
   пропускается. На дату — одна транзакция: ученик убирается из всех уроков старой группы в этот день (урок без
   учеников помечается на удаление), записывается в урок новой; любой отказ — откат. ТЧ групп в карточке ученика
   не меняется (при флажке «только выбранные» без новой группы в ТЧ перевод откатится по правилу 5).
10. **Панель ученика** (`Пан:27-265`): даты уроков группы на период — по флажкам дней, начало — время дня, без него —
    общее `Время` (`Пан:216-224`); длительность — время дня, если конец > начала, иначе `Продолжительность`
    (`Пан:239-249`); урок группы на дату ищется по точному началу и группе (`Пан:268-287`); новый урок — по группе
    (педагог, предмет, помещение, ставка, организация панели) **без проверки конфликтов плана**; тариф — последний
    урок ученика в группе → тариф группы → тариф ученика (`Пан:290-317`); перевод — удаление за период + запись в
    даты новой группы с первой по последнюю дату, одной транзакцией (`Пан:110-151`).
11. **Календарь** (`Кал`): фильтр по группе/педагогу/помещению/статусу/ученику (`Кал:95-185`); новый урок из
    ячейки — педагог, ставка, предмет, тариф группы из фильтра, помещение — из ячейки/фильтра, не из группы
    (`Кал:781-818`); ученики группы не подставляются. Расписание группы (дни/время) в календаре не рисуется; фоном —
    только график педагога (`Кал:240-266`).
12. **График рабочего времени педагога** (`Граф\Ext\ObjectModule.bsl`): дата документа всегда приводится к концу
    месяца (`:43`); второй проведённый график педагога за месяц не проводится (`:10-41`). ТЧ: Дата, ВремяНачала,
    ВремяОкончания (время — дата 01.01.0001).
13. **Урок против графика** (`УМ:409-478`, вызов `УМ:577-584` при проведении, `ФормаДокумента:161-176` — вопрос
    перед проведением): графика за месяц нет — проверки нет; график есть — урок должен целиком лежать в интервале
    строки этого дня, иначе **предупреждение** (не отказ). День, которого нет в графике, — тоже предупреждение.
    Помощник/панель записывают будущие уроки без этой проверки (только при проведении).
14. **Пересечения** урока с уроками того же педагога или помещения — отказ при проведении (`УМ:586-609`,
    `УО:200`); группа при проведении на пересечение не проверяется (только помощником при создании, `УМ:824-864`).
15. **Регистр** `УЗ_СписанияСуммЗаУроки` хранит измерение `ГруппаОбучения` (`УО:139`, `Documents\УЗ_СписаниеОстатков\Ext\ObjectModule.bsl:23`)
    — отчёты «Взаиморасчёты», «Явки_2», «Аналитика по ученикам» группируют по нему.

## 4. Расхождения и следы трёх режимов

- **Р1. Длительность урока группы — три правила** (общая / время дня / время дня с откатом на общую). Группа
  ПН 17:00–18:30, общая 1 ч: форма урока даст 1 ч, помощник 1,5 ч, продление 1 ч, панель 1,5 ч.
- **Р2. Время начала:** продление ставит общее время во все дни, игнорируя время дня.
- **Р3. Состав группы — три источника** (ТЧ на сегодня / ТЧ «только выбранные» без дат / последний урок) плюс
  панель, которая считает «группы ученика» по истории уроков. Нет одного ответа «кто в группе на дату».
- **Р4. Членство на дату урока не проверяется:** помощник берёт состав на сегодня, а уроки ставит на месяц вперёд;
  проверка урока игнорирует `ДатаНачала`.
- **Р5. «Только выбранные группы» — фильтр наоборот в помощнике** (`Пом:463`): при «добавлять в существующие»
  подтягиваются только ученики с флажком; обычные ученики с группой в ТЧ — нет (до перезаполнения при смене группы).
- **Р6. Конфликты плана** проверяет только помощник (создание/перевод); продление и панель могут записать план
  поверх урока того же педагога/помещения — отказ всплывёт только при проведении после начала урока.
- **Р7. Перевод:** в помощнике даты — по дням группы «из», время — группы «в», несовпадающие дни молча пропадают;
  в панели даты — по дням группы «в» за тот же период. Карточка ученика (ТЧ) в обоих случаях не обновляется.
- **Р8. Помещение группы** игнорируется календарём (берётся ячейка).
- **Р9. Продление без уроков группы** — ошибка выполнения вместо сообщения (`Пом:171, 210`).
- **Р10. Сутки:** `ДобавитьВСписок` — `ТекущаяДата()` (компьютер сервера), остальное — `ТекущаяДатаСеанса()`.
- **Режимы.** Рок-школа (индивидуальные, почасовые): урок без группы — ручное время в помощнике, нет расписания,
  график педагога — главный инструмент планирования; тариф ученика (почасовой) важнее тарифа группы в помощнике и
  форме урока, но не в панели. Школа математики (группы, поурочно, абонементы): расписание по дням, «только выбранные
  группы», абонемент подставляет только помощник при смене группы; продление и панель абонемент не ставят →
  списание по тарифу, а не по абонементу (В2). Школа робототехники (группы + наборы/материалы): у группы нет
  реквизита «набор/материалы» и нет ТЧ расходов; доп. расходы урока (`ТЧ Расходы`) вводятся в каждом уроке вручную
  и ни помощником, ни продлением, ни панелью не переносятся; стоимость материалов на ученика не начисляется.

## 6. Вопросы владельцу

1. Длительность урока группы: время дня недели главнее общей длительности (как помощник)? — предлагается да,
   общая — только если у дня нет времени (как панель).
2. Робототехника: нужен ли у группы «набор/материалы» (стоимость на ученика, добавляется в каждый урок группы)
   или материалы — только доп. расходы урока, как сейчас?
3. Перевод из группы должен закрывать строку старой группы и открывать новую в ТЧ карточки ученика? (как «кадровый
   перевод» в типовых — предлагается да, датой перевода).
