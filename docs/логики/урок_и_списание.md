# Логика: урок и списание оплаты за занятие

Разбор 28.09.2026 по исходникам расширения `src_ext` (только чтение кода; базы не открывались). Пути ниже — от `src_ext\`.
Сокращения: **УМ** = `Documents\УЗ_Урок\Ext\ObjectModule.bsl`, **ММ** = `Documents\УЗ_Урок\Ext\ManagerModule.bsl`,
**ФУ** = `Documents\УЗ_Урок\Forms\ФормаДокумента\Ext\Form\Module.bsl`, **ПУ** = `Documents\УЗ_Урок\Forms\ПомощникСозданияУроков\Ext\Form\Module.bsl`,
**Рег** = регистр накопления `УЗ_СписанияСуммЗаУроки` (остатки: Часы, Сумма, КоличествоУроков, КоличествоЯвок).

## 1. Назначение

Урок — факт проведённого занятия: кто из учеников был (явка), с кого брать деньги («К оплате»), сколько (цена по
абонементу или тарифу, минус скидка), сколько занятий/часов списать с абонемента, сколько начислить педагогу, какие
доп. расходы и бонусы по картам. Проведённый урок уменьшает остаток денег ученика (долг/аванс по организации — В12)
и остаток занятий абонемента. Один документ обслуживает и индивидуальный урок (рок-школа: один ученик, почасовой
тариф), и групповой (математика: 10 учеников, поурочный тариф или абонемент; робототехника: группа + доп. расходы).

## 2. Правила как есть

1. Дата урока без секунд — `УМ:4-6`. Организация нового урока — из настроек — `УМ:8-11`.
2. Длительность `КоличествоЧасов` хранится с 4 знаками (12.4), все расчёты — от целых минут: `СекундУрока = Окр(ч×60)×60`,
   `ЧасовУрока = Окр(ч×60)/60` (В13) — `ММ:201-208`; окончание урока — `УМ:31`, в форме тем же выражением — `ФУ:137`.
3. Цена строки пересчитывается при каждой записи (`УМ:28` → `ММ:342-407`), ручной цены нет (поле только чтение).
4. Строка без «К оплате» — цена 0 (`ММ:357-358`), независимо от явки — это «бесплатное занятие».
5. Строка «К оплате»: если абонемент строки подходит (ученик и предмет, `ММ:213-221`) и у него есть цена —
   **цена абонемента / КоличествоЗанятий**, для часового абонемента — **цена × часы урока / КоличествоЧасов** (В2, `ММ:227-238`);
   иначе по тарифу на дату урока (`ММ:367-368`, `ММ:183-195`): **уроковый тариф — Сумма / КоличествоУроков (часы урока
   не влияют)**, часовой — `Сумма × часы урока / КоличествоЧасов`. Приоритет у «уроков» (`ММ:188` раньше `ММ:190`).
6. Цена округляется до копеек до скидки; скидка и сумма — от округлённой цены, `Цена = Сумма + СуммаСкидки` (`ММ:384-398`).
   Скидка — `ММ:149-170` (см. `тарифы_скидки_бонусы.md`). Настройка «ИспользоватьОкругление» — дополнительно каждое
   из трёх чисел до рубля по отдельности (`ММ:399-403`).
7. Итоги шапки (Сумма, СуммаСкидки, СуммаБонусов, НачисленоПедагогу, СуммаДопРасходов) — `УМ:35-39`.
8. **В10**: урок, чья дата позже текущей, не проводится — `УМ:59-68`; программная запись будущего урока — только
   записью (план), проведённый будущий урок распроводится — `CommonModules\УЗ_Общий\Ext\Module.bsl:80-87`.
9. Дата запрета — подпиской `УЗ_ДатаЗапретаПередЗаписью` (модуль `УЗ_ДатыЗапрета`), в проведении не дублируется — `УМ:55`.
10. Настройка «Требовать описание к неоплаченным урокам» (с даты): строка без «К оплате» без заметки — отказ — `УМ:77-85`, `УМ:215-224`.
11. Строка без явки и без «К оплате» — **движений нет вообще** — `УМ:87-89`.
12. «К оплате» без цены (нет цены абонемента и тариф пуст или без цены на дату) — отказ — `УМ:94-109`.
    **Цена 0, посчитанная по существующей цене (урок 0 ч по часовому тарифу), не ловится**.
13. **Р7/В3**: абонемент расходует только строка «К оплате» (в т.ч. неявка); явка без оплаты абонемент не трогает — `УМ:113`.
14. Проверки абонемента (`УМ:254-342`): владелец = ученик, предмет абонемента = предмет урока или пуст, активен и
    активирован, не приостановлен на день урока, дата начала ≤ дня урока, срок + дни приостановок ≥ дня урока (В4,
    `ММ:239-287`), остаток: **по занятиям** — `КоличествоЗанятий − использовано ≥ 1` (`УМ:317-322`), **по часам** —
    в секундах (`УМ:323-333`). Если у абонемента заполнены и занятия, и часы — проверяются только занятия.
    Несколько строк одного абонемента в уроке учитываются (`УМ:298-302`, `337-338`); остаток читается под
    исключительной блокировкой (`УМ:228-246`).
15. Движение Рег на строку (Расход) — `УМ:128-146`:
    | Ресурс | Что пишет урок | Смысл |
    |---|---|---|
    | Часы | `+СекундУрока(часы урока)` | секунды урока **на каждого ученика** (ученико-часы), остаток уходит в минус |
    | Сумма | `Стр.Сумма` (после скидки) | деньги, списанные с ученика |
    | КоличествоУроков | `−1` | ученико-урок; остаток растёт на +1 (число использованных) |
    | КоличествоЯвок | `−1` только при явке | ученико-явка |
    Измерения: Клиент, Педагог, Предмет, Тариф, Скидка, Группа, Организация, Явка, Абонемент (только у «К оплате»).
    **Знаки разные**: Часы в Расходе положительные, КоличествоУроков — отрицательные; все потребители это компенсируют
    (`УМ:326` `−ЧасыОстаток`; карточка абонемента `ЧасыРасход/3600`, `КоличествоУроковОборот`).
16. Бонусы строки: карта проверяется по сроку (общая функция с ПКО, `Documents\УЗ_ПриходДенег\Ext\ManagerModule.bsl:137-156`),
    движение `УЗ_ДвижениеДисконтныхКарт` — **Приход** (урок **начисляет** бонусы, сумму вводят руками), Сумму урока
    бонусы не уменьшают — `УМ:148-170` (комментарий «Расход» в `УМ:161` неверен).
17. Начисления педагогу (Приход `УЗ_РасчетыПоЗарплате`) — `УМ:175-187`, расчёт `ММ:28-102` (В6: без явки «за занятие» и
    «за час» не начисляются; «с человека» — по явкам; «% с оплаты» — от суммы строк). Ставка вне срока — предупреждение `УМ:203-210`.
18. Доп. расходы урока — Расход `УЗ_Расходы` на каждую строку, независимо от явки — `УМ:190-198`.
19. Пересечения (только проведённые уроки того же педагога или помещения, стык 12:00→12:00 не пересечение, допуск 30 с)
    — отказ проведения `ММ:572-608`, запрос `ММ:481-557`; ученика никто не проверяет (ученик может быть на двух уроках сразу).
    График рабочего времени педагога — только предупреждение (`ММ:409-468`, в форме — вопрос `ФУ:161-191`).
20. Ученик с «только выбранными группами»: группа не разрешена или срок группы у ученика истёк — отказ записи (`УМ:19-21`, `УМ:367-396`).
21. Статус урока (`Справочник.УЗ_Статусы`) — только отбор в календаре (`DataProcessors\УЗ_Календарь\Forms\ФормаКалендарь\Ext\Form\Module.bsl:104-174`);
    реквизиты статуса `ЗащитаОтИзменений`, `Активно`, `ИзменятьСтатус` кодом **не используются**.
22. Тема урока и домашнее задание (`ТемаУрока`, `ДомашнееЗадание`) — только поля формы, в движениях, печати, панели ученика не участвуют.
23. Другие документы в Рег: **СписаниеОстатков** — Расход с теми же знаками, что урок (`Documents\УЗ_СписаниеОстатков\Ext\ObjectModule.bsl:7-25`),
    Часы из часов строки; **ПКО** «Касса ученики» — Приход только Суммы (+ сумма бонусов) с измерением Абонемент
    (`Documents\УЗ_ПриходДенег\Ext\ObjectModule.bsl:31-43, 84-95`), Часы/Уроки/Явки не пишет.

## 4. Расхождения и следы трёх режимов

**Рок-школа (индивидуально, почасово):**
- Р1. Часовой тариф — единственный, где длительность влияет на цену. Урок 0 ч «К оплате» по часовому тарифу проводится
  с суммой 0 (правило 12 не ловит) — молча бесплатный урок.
- Р2. Колонка «Часы» у строки ученика (`ФУ` элемент `УченикиЧасы`, обработчик `ФУ:456-458`) привязана к удалённому реквизиту
  (DataPath — UUID, в LM_Урок реквизита уже нет) — след индивидуальной длительности на ученика; колонка скрыта, мёртвая.
- Р3. `Часы` в Рег — ученико-секунды: у группы из 10 за урок 1,5 ч пишется 15 ч. Для рок-школы «часы ученика = часы
  педагога», для группы — нет; отчёт `Reports\УЗ_АналитикаПоУченикам` (`ЧасыРасход`, свёртка по предмету `:208, :234, :261`)
  показывает ученико-часы, а не часы занятий.
- Р4. Точность часов: урок 12.4, тариф 10.1, абонемент 6.1. «8 занятий по 40 мин» в часовом абонементе не выразить:
  5,3 ч = 19 080 с < 8 × 2 400 = 19 200 с — восьмое занятие отказывается (сценарий 7).

**Школа математики (группы, поурочно, абонементы):**
- М1. Тариф строки в группе выбирается **тремя разными правилами** (таблица §3): форма и помощник — личный тариф ученика
  важнее тарифа группы; панель — тариф группы важнее личного. Ученик рок-школы с личным «2 000 за час» в группе 1,5 ч
  математики получает 3 000 из формы и помощника, но 500 (тариф группы) из панели (сценарий 9).
- М2. Смена группы в форме ставит тариф урока (`ФУ:442-444`), но строки учеников не меняет и вопроса «изменить у всех» не
  задаёт (вопрос есть только при ручной смене тарифа, `ФУ:482-511`).
- М3. Поурочный тариф и абонемент по занятиям не зависят от длительности: урок 2 ч по абонементу 6 400/8 стоит 800, как и 1 ч.
- М4. Панель ученика не подставляет абонемент — урок, созданный панелью, абонемент не расходует и берёт деньги по тарифу.
- М5. Помощник подбирает абонемент на **сегодня** (`ПУ:409-410`), а уроки создаёт на будущие даты — абонемент, который
  кончится через неделю, подставится в уроки следующего месяца (и те не проведутся); новый абонемент следующего месяца не подставится.
- М6. Панель считает «осталось N из M» по исходной дате окончания (без продления на приостановки В4) и суммирует
  занятия всех активных абонементов предмета, в т.ч. ещё не начавшихся.
- М7. Абонемент без предмета (универсальный): ПКО «на основании абонемента» берёт пустой предмет абонемента
  (`Documents\УЗ_ПриходДенег\Ext\ObjectModule.bsl:132-139`), уроки пишут предмет урока — «Задолженность по предмету»
  в уроке (`ФУ:7-16`) показывает долг при оплаченном абонементе (сценарий 11).
- М8. Скидка строки применяется и к цене абонемента (`ММ:386`) — если цена абонемента уже со скидкой, скидка двойная;
  сумма уроков по абонементу не равна цене абонемента (сценарий 10).
- М9. Округление: цена абонемента / занятия до копеек: 1 000 / 3 = 333,33 → три урока = 999,99, у ученика «переплата» 0,01.

**Школа робототехники (группы, наборы/материалы, доп. расходы):**
- Т1. Материалы ученику не начисляются: в уроке нет строки «материалы/набор» на ученика; доп. расходы урока (`УМ:190-198`)
  — только расход студии по статье, в долг ученика не идут. Плата за набор возможна лишь отдельным тарифом/ПКО.
- Т2. Доп. расходы урока пишутся при любой явке (и если никто не пришёл); тот же расход можно провести и уроком, и
  документом `УЗ_ДополнительныеРасходы` «на основании урока» (`Documents\УЗ_ДополнительныеРасходы\Ext\ObjectModule.bsl:14-17, 28-37`) — дубль не контролируется.

**Общие:**
- О1. СписаниеОстатков пишет в Рег без измерений Абонемент, Явка, Скидка — занятия абонемента им не поправить; строка с
  «Кол-во явок» 1 получает `Явка = Ложь`, у урока явка −1 всегда с `Явка = Истина`.
- О2. Бонусы в уроке — начисление (Приход) вручную, даже на бесплатную явку; строки без явки и оплаты бонусы молча теряют (правило 11).
- О3. Карточка ученика считает «остаток единиц» по карточке тарифа (`Тариф.Сумма`), урок — по истории цен на дату (В8).
- О4. `CommonModules\УЗ_Сервер\Ext\Module.bsl:1-25` `ПолучитьОстаткиЧасовИСумм` — мёртвая (вызовов нет), складывает дату
  с секундами (`'00010101' + ЧасыОстаток`) — при отрицательном остатке упала бы.
- О5. Нигде не проверяется, что ученик не стоит в двух уроках одновременно (пересечения — только педагог и помещение).
- О6. Статус урока ничего не блокирует; «Защита от изменений» у статуса — пустой флажок.
