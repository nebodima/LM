## 1. Исправлять первым — деньги (однозначные дефекты, решения владельца не требуют)

1. **Зарплата выплачивается дважды**: расчёт расширяет период до месяца и не исключает уже рассчитанные уроки (учёт №2, Codex).
2. **Бонусы без остатка**: пустая карта (0) — проверка пропускается, ПКО зачисляет бонусы из ничего (учёт №3, Codex).
3. **«Списание остатков» пишет часы как секунды** (нет `* 3600`) (учёт №6).
4. **Цена урока не пересчитывается** при смене часов/даты/группы; срок скидки не проверяется; скидка может сделать сумму отрицательной (учёт №5, №9, Codex).
5. **Массовое изменение уроков не обновляет движения** (Codex).
6. **Расчёт зарплаты может менять закрытый период** — даты движений не проверяются запретом (Codex B04).
7. **Возврат денег из карточки ученика не проводится** — обращение к несуществующей табличной части (учёт №4) [проверить на базе].
8. **Перемещение и «Остаток в кассе»** — остаток берётся по первой строке (учёт №7–8). *Codex считает, что платформа сворачивает разрезы и это не ошибка — проверить на базе, потом решать.*
9. **Нет блокировок данных при проведении** — одновременные уроки/оплаты могут перерасходовать абонемент и бонусы (Codex 5.5, учёт).
10. **Урок проводится заранее в будущее, и зарплата за него уже начисляется** (бета №3).
11. **Пересечения уроков** (педагог/класс в одно время) только сообщаются, не запрещают; часть пересечений не видна (Codex 5.5).

## 2. Интерфейс — ломается у покупателя

1. **Настройки не редактируются**: запись открывается «(создание)», при записи «уже существует» — регресс переделки регистра без измерений (бета №1).
2. **14 обработчиков указаны в формах, процедур нет** — кнопки и события молча не работают (проверки №1, файловый аудит «обработчики»); «Переместить деньги» в расчёте зарплаты падает (`ПолучитьОсновнуюКассу`).
3. **Предоплата показана как долг** в «Панели ученика» (бета №2).
4. Помощник уроков: не подтягивает учеников группы, «нет действующих цен» при наличии цены (бета №4–5).
5. Абонемент без поля «Тариф» — всё вручную (бета №7); «Это педагог» перестраивает карточку и путает поля (бета №9).

## 3. Безопасность и совместимость

1. **Запросы к Организациям без `РАЗРЕШЕННЫЕ`** — при включённом ограничении доступа по организациям у сотрудника не откроется ни одна форма документа (безопасность №1).
2. **Отчёт «Движения документа» в привилегированном режиме принимает любой документ**, в т.ч. хозяина — обход прав (безопасность №5, Codex).
3. Одна роль на всех: зарплата, ставки, настройки доступны любому сотруднику — нужна вторая роль «руководитель» (безопасность №7–8).
4. Пустые `Исключение … КонецПопытки` (~20 мест) — ошибки теряются молча.
5. 1С:Фреш: план обмена `МиграцияПриложений` не заимствован, `Вычислить` на сервере, почта без разрешений — решать, заявляем ли Фреш.

## 4. Проверки — зелёные не значит верно

1. Нет сквозного теста урок → оплата → долг → зарплата → выдача, нет отмены проведения/перепроведения; суммы движений ни один тест не сверяет.
2. «Высота отчёта > 0» и `т.проверить(True)` — зелёные по построению.
3. Уборка тестов оставляет движения удалённых документов («<Объект не найден>» в отчётах тестовых баз).
4. Деплой: разбор лога по словам, прогон без таймаута, красный аудит не останавливает загрузку.
5. Файловые аудиты: 266 замечаний — 127 компоновка (цвета числом, высоты), 54 BOM, 33 иконки, 14 «Комментарий последним», 14 обработчиков, 5 дублей, 2 мёртвых макета.
