## Кнопки и действия

- [уточнить] подпись стандартной кнопки — открывает создание новой карточки. <!-- src: src_ext/Catalogs/УЗ_Абонемент/Forms/ФормаСписка/Ext/Form.xml:5 -->

- [уточнить] подпись стандартной кнопки — открывает создание группы справочника. <!-- src: src_ext/Catalogs/УЗ_Абонемент/Forms/ФормаСписка/Ext/Form.xml:11 -->

- [уточнить] подпись стандартной кнопки — создаёт копию выбранной записи. <!-- src: src_ext/Catalogs/УЗ_Абонемент/Forms/ФормаСписка/Ext/Form.xml:17 -->

- [уточнить] подпись кнопки для документа «Приход денег (ПКО)» — открывает создание документа «Приход денег (ПКО)» на основании текущей записи. <!-- src: src_ext/Catalogs/УЗ_Абонемент/Forms/ФормаСписка/Ext/Form.xml:31; src_ext/Documents/УЗ_ПриходДенег.xml:26 -->

## Результат

Форма показывает записи справочника; дальнейшее действие определяется выбранной командой из раздела выше. <!-- src: src_ext/Catalogs/УЗ_Абонемент/Forms/ФормаСписка/Ext/Form.xml:59 -->
