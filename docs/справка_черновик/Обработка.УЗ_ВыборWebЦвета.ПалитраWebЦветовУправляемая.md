# Палитра цветов

Форма помогает выбрать цвет и возвращает его в окно, из которого её открыли. После выбора палитра закрывается. <!-- src: src_ext/DataProcessors/УЗ_ВыборWebЦвета/Forms/ПалитраWebЦветовУправляемая/Ext/Form/Module.bsl:143 -->

## Как пользоваться

[уточнить] Пошаговое описание выбора и подписи вариантов: в разметке формы предусмотрено место для палитры, а сами варианты создаются во время открытия. В Form.xml нет отдельных элементов этих вариантов, поэтому их названия здесь не перечислены. <!-- src: src_ext/DataProcessors/УЗ_ВыборWebЦвета/Forms/ПалитраWebЦветовУправляемая/Ext/Form.xml:27 --> <!-- src: src_ext/DataProcessors/УЗ_ВыборWebЦвета/Forms/ПалитраWebЦветовУправляемая/Ext/Form/Module.bsl:61 -->

## Результат и сообщения

Результат формы — выбранный цвет. Обработчик выбора заканчивается закрытием формы с этим значением. <!-- src: src_ext/DataProcessors/УЗ_ВыборWebЦвета/Forms/ПалитраWebЦветовУправляемая/Ext/Form/Module.bsl:149 -->

Отдельных сообщений об ошибках в обработчике выбора нет. <!-- src: src_ext/DataProcessors/УЗ_ВыборWebЦвета/Forms/ПалитраWebЦветовУправляемая/Ext/Form/Module.bsl:143 -->
