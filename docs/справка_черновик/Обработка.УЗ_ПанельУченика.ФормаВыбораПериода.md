# Выбор дней занятий

Форма выбирает конкретные дни занятий для панели ученика. При открытии она получает ранее выбранные даты, группу и границы периода из вызывающей формы. <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form/Module.bsl:3 -->

## Что заполнить

1. В календаре с подписью «Выберите дни зажав Ctrl + левая кнопка мыши» отметьте нужные даты. Ранее выбранные даты отмечаются при открытии. <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form.xml:32 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form.xml:75 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form/Module.bsl:5 -->
2. При необходимости выберите «Группа обучения»: изменение группы очищает прежнее выделение и заполняет даты по её расписанию в переданном периоде. Если группа не выбрана, заполнение прекращается. <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form.xml:50 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form.xml:89 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form/Module.bsl:22 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form/Module.bsl:29 -->
3. Нажмите «Выбрать», чтобы вернуть выделенные даты в панель ученика и закрыть окно. <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form.xml:21 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form/Module.bsl:16 -->

## Кнопки

- «Заполнить даты из группы обучения» повторно отмечает дни по расписанию выбранной группы; к датам добавляется время начала занятий группы. <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form.xml:58 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form.xml:151 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form/Module.bsl:35 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form/Module.bsl:42 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form/Module.bsl:85 -->
- «Выбрать» передаёт выделение вызывающей форме. Сам обработчик этой команды документы не записывает. <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form.xml:21 --> <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form/Module.bsl:16 -->

## Сообщения и результат

Для пустой группы в процедуре заполнения предусмотрен выход без сообщения. Собственных сообщений об ошибках при выборе дат в модуле нет. <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/ФормаВыбораПериода/Ext/Form/Module.bsl:29 -->

[уточнить] Передача изменённого набора дат обратно в панель ученика: принимающий обработчик сначала заменяет список неопределённым значением, затем пытается добавлять в него даты. Успешное применение выбранных дат этим фрагментом не подтверждено. <!-- src: src_ext/DataProcessors/УЗ_ПанельУченика/Forms/Форма/Ext/Form/Module.bsl:704 -->
