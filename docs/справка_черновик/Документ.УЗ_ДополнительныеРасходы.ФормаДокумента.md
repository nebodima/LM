# Доп. расходы

Форма фиксирует дополнительные расходы студии по статьям затрат. При проведении суммы строк попадают в учёт расходов. <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы/Ext/ObjectModule.bsl:26 -->

Проверьте «Дата», «Организация». <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы/Forms/ФормаДокумента/Ext/Form.xml:57 --> <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы/Forms/ФормаДокумента/Ext/Form.xml:78 --> <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы.xml:93 -->

В каждой строке заполните «Статья затрат», «Сумма». <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы/Forms/ФормаДокумента/Ext/Form.xml:130 --> <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы.xml:323 --> <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы/Forms/ФормаДокумента/Ext/Form.xml:137 --> <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы.xml:360 -->

**Движения документа** — открывает отчёт о движениях этого документа. <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы/Forms/ФормаДокумента/Ext/Form.xml:29 --> <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы/Forms/ФормаДокумента/Ext/Form/Module.bsl:18 -->

## После записи и проведения

При записи итог документа равен сумме строк расходов. При проведении для каждой строки записывается расход по соответствующей статье и организации. <!-- src: src_ext/Documents/УЗ_ДополнительныеРасходы/Ext/ObjectModule.bsl:8 -->
