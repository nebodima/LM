# Тарифы — карточка

Хранит стоимость выбранного количества уроков или часов. <!-- src: src_ext/Catalogs/УЗ_Тарифы.xml:26; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:308 -->

## Порядок работы

1. Заполните «Название тарифа» и при необходимости «Группа». При открытии новой карточки пустое название заменяется на слово «Тариф» с текущей датой. <!-- src: src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:64; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:29; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:7 -->

2. Для простой цены оставьте «Использовать историю цен» выключенным. Заполните «Кол-во часов» или «Кол-во уроков», затем «Сумма за все часы/уроки»: ввод количества одного вида обнуляет другой. <!-- src: src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:88; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:135; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:146; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:162; src_ext/Catalogs/УЗ_Тарифы.xml:516; src_ext/Catalogs/УЗ_Тарифы.xml:337; src_ext/Catalogs/УЗ_Тарифы.xml:382; src_ext/Catalogs/УЗ_Тарифы.xml:471; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:75; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:143; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:149 -->

3. Для цен с датой действия включите «Использовать историю цен»: вместо одиночной цены появляется таблица. «Создать цену» открывает отдельную форму цены с выбранным тарифом. <!-- src: src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:88; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:176; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:205; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:50; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:75 -->

## Кнопки и действия

- [уточнить] подпись стандартной кнопки — сохраняет карточку и закрывает её. <!-- src: src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:7 -->

- [уточнить] подпись стандартной кнопки — сохраняет карточку. <!-- src: src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:14 -->

- «Создать цену» — открывает форму цены с текущим тарифом. Для ещё не сохранённого тарифа сначала предлагает сохранить карточку. <!-- src: src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:205; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:359; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:20 -->

## Результат

После записи сохраняются сведения этой карточки справочника. <!-- src: src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form.xml:308; src_ext/Catalogs/УЗ_Тарифы.xml:26 -->

## Сообщения и неясные места

- «Не указано количество уроков/часов!!!» и «Не указана сумма!!!» — предупреждения при нулевых значениях. В модуле объекта отказ записи для этих проверок закомментирован. <!-- src: src_ext/Catalogs/УЗ_Тарифы/Ext/ObjectModule.bsl:4; src_ext/Catalogs/УЗ_Тарифы/Ext/ObjectModule.bsl:9 -->

- «Не заполнено наименование тарифа!» — создание цены прекращается, если новый тариф не имеет названия. «Тариф еще не записан! Записать?» — предложение сохранить новый тариф перед созданием цены. <!-- src: src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:22; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:25; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:30 -->

- «Нет действующих цен! Создайте новую цену!» — для сохранённого тарифа не найдена действующая цена на текущую дату. <!-- src: src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:99; src_ext/Catalogs/УЗ_Тарифы/Forms/ФормаЭлемента/Ext/Form/Module.bsl:130 -->
