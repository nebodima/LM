## Порядок работы

Сначала найдите нужную строку по данным в таблице, затем используйте доступную команду. Состав колонок приведён ниже. <!-- src: src_ext/Catalogs/УЗ_Скидки/Forms/ФормаСписка/Ext/Form.xml:37 -->

| Действует с | Начало действия скидки. <!-- src: src_ext/Catalogs/УЗ_Скидки/Forms/ФормаСписка/Ext/Form.xml:122; src_ext/Catalogs/УЗ_Скидки.xml:191 --> |
| по | Окончание действия скидки. <!-- src: src_ext/Catalogs/УЗ_Скидки/Forms/ФормаСписка/Ext/Form.xml:128; src_ext/Catalogs/УЗ_Скидки.xml:234 --> |

## Кнопки и действия

- [уточнить] подпись стандартной кнопки — открывает создание новой карточки. <!-- src: src_ext/Catalogs/УЗ_Скидки/Forms/ФормаСписка/Ext/Form.xml:5 -->

- [уточнить] подпись стандартной кнопки — открывает создание группы справочника. <!-- src: src_ext/Catalogs/УЗ_Скидки/Forms/ФормаСписка/Ext/Form.xml:11 -->

- [уточнить] подпись стандартной кнопки — создаёт копию выбранной записи. <!-- src: src_ext/Catalogs/УЗ_Скидки/Forms/ФормаСписка/Ext/Form.xml:16 -->

## Результат

Форма показывает записи справочника; дальнейшее действие определяется выбранной командой из раздела выше. <!-- src: src_ext/Catalogs/УЗ_Скидки/Forms/ФормаСписка/Ext/Form.xml:37 -->
