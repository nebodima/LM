# Движения документа

Форма показывает, какие активные записи создал выбранный документ в регистрах учёта. Она нужна для проверки результата документа по суммам и другим данным движений. <!-- src: src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form/Module.bsl:97; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form/Module.bsl:440; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form/Module.bsl:477 -->

## Как пользоваться

Документ передаётся при открытии, после чего результат формируется автоматически. Поле «Документ» и кнопка «Сформировать» находятся в скрытой группе; поле дополнительно доступно только для чтения. Поэтому ручной выбор документа в этой форме не предлагается. <!-- src: src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form.xml:17; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form.xml:35; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form.xml:37; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form.xml:42; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form.xml:80; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form.xml:93; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form/Module.bsl:513 -->

Если скрытая группа будет показана другим кодом, «Сформировать» вызывает повторное получение движений. [уточнить] В данном модуле показ этой группы не реализован; обычный пользовательский путь повторного формирования по исходникам не подтверждён. <!-- src: src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form.xml:17; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form.xml:46; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form/Module.bsl:525 -->

## Результат и сообщения

В результат попадают активные записи регистров сведений и накопления. Приход выделяется синим, расход — красным; отчёт читает движения выбранного документа, а не проводит его повторно. <!-- src: src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form/Module.bsl:97; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form/Module.bsl:333; src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form/Module.bsl:466 -->

«Не выбран документ!» — при открытии не передан заполненный документ. Формирование прекращается. <!-- src: src_ext/Reports/УЗ_ДвиженияДокумента/Forms/ДвиженияДокумента/Ext/Form/Module.bsl:429 -->
