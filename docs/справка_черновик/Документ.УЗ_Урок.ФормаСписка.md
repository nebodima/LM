# Уроки — список

Список служит для просмотра документов и выбора нужной записи; состав доступных колонок приведён ниже. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:301 -->

## Как работать

Для отбора уроков задайте «Отбор по ученику», «Абонемент». <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:170 --> <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:202 -->

Отбор по ученику показывает уроки с этим учеником; отбор по абонементу — уроки с выбранным абонементом. При очистке соответствующий отбор выключается. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form/Module.bsl:132 -->

**Помощник создания уроков** — открывает помощник создания уроков. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:19 --> <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form/Module.bsl:116 -->

**Взаиморасчеты** — открывает отчёт по взаиморасчётам; выбранный в отборе ученик передаётся в настройки отчёта. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:70 --> <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form/Module.bsl:315 -->

**Взаиморасчеты** — открывает тот же отчёт по взаиморасчётам. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:233 --> <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form/Module.bsl:315 -->

**Взаиморасчеты по ФизЛицу** — открывает взаиморасчёты по ученику из текущей строки расшифровки. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:635 --> <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form/Module.bsl:327 -->

Если детализация включена, выбор урока обновляет расшифровку его учеников. В веб-клиенте обработчик выбора строки принудительно отключает детализацию. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form/Module.bsl:78 -->

Для состава дополнительных сведений предусмотрены «Не отображать детализацию урока», «Отображать диаграмму задолженности», «Отображать ближайшие дни рождения». <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:253 --> <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:1394 --> <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:263 --> <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:1380 --> <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:280 --> <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:1366 -->

**Календарь** — открывает календарь. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:76 -->

**Явки** — открывает отчёт посещаемости. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:93 -->

**Изменение уроков** — открывает обработку изменения уроков. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:103 -->

## Запись и проведение

Это форма списка: суммы и часы изменяются при выполнении операций с документом, а не при просмотре колонок. Правила документа описаны в отдельной справке. <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:301 -->

[Открыть описание документа](Документ.УЗ_Урок.ФормаДокумента.md). <!-- src: src_ext/Documents/УЗ_Урок/Forms/ФормаСписка/Ext/Form.xml:301 -->
