# Настройки — запись

Здесь задаются организация и касса по умолчанию, а также параметры оповещений студии. Настройки хранятся одной общей записью. <!-- src: src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:9; src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:14; src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:30; src_ext/InformationRegisters/УЗ_Настройки/Ext/ManagerModule.bsl:7 -->

## Что заполнить

1. Выберите «Организация по умолчанию» и «Касса по умолчанию». Эти значения входят в общую структуру настроек, используемую при заполнении документов. <!-- src: src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:9; src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:14; src_ext/InformationRegisters/УЗ_Настройки.xml:75; src_ext/InformationRegisters/УЗ_Настройки.xml:114; src_ext/InformationRegisters/УЗ_Настройки/Ext/ManagerModule.bsl:4; src_ext/InformationRegisters/УЗ_Настройки/Ext/ManagerModule.bsl:14 -->
2. Отметьте «Использовать оповещения», если нужна проверка задолженности. При включении нулевые значения заменяются: «Период оповещения (секунд)» — на 300, «Оповещать о задолженности за» — на 2. При снятом флажке эти два поля недоступны. <!-- src: src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:30; src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:39; src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:51; src_ext/InformationRegisters/УЗ_Настройки.xml:273; src_ext/InformationRegisters/УЗ_Настройки.xml:312; src_ext/InformationRegisters/УЗ_Настройки.xml:356; src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form/Module.bsl:3; src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form/Module.bsl:27; src_ext/CommonModules/УЗ_Сервер/Ext/Module.bsl:37 -->
3. «Период оповещения (секунд)» используется для проверки оповещений в сеансе, но фактическое значение не может быть меньше 30 секунд. <!-- src: src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:39; src_ext/InformationRegisters/УЗ_Настройки.xml:312; src_ext/CommonModules/УЗ_Сервер/Ext/Module.bsl:120 -->

## Важные ограничения

[уточнить] «Оповещать о задолженности за» сопровождается надписью «дней», однако код проверки задолженности использует значение только как признак нуля/ненуля и выбирает текущий отрицательный денежный остаток; расчёта срока на указанное число дней здесь нет. <!-- src: src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:51; src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:58; src_ext/InformationRegisters/УЗ_Настройки.xml:356; src_ext/CommonModules/УЗ_Сервер/Ext/Module.bsl:37; src_ext/CommonModules/УЗ_Сервер/Ext/Module.bsl:43 -->

«Использовать округление» округляет цену тарифа, итоговую сумму и сумму скидки в строках урока до целых чисел. <!-- src: src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:71; src_ext/InformationRegisters/УЗ_Настройки.xml:153; src_ext/Documents/УЗ_Урок/Ext/ManagerModule.bsl:169; src_ext/Documents/УЗ_Урок/Ext/ManagerModule.bsl:220 -->

[уточнить] «Требовать описание к неоплаченным урокам» и «Требовать описание к неоплаченным урокам с» сохраняются, но проверка описания в расчёте урока закомментирована. Нельзя обещать запрет записи по этим настройкам. <!-- src: src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:77; src_ext/InformationRegisters/УЗ_Настройки/Forms/ФормаЗаписи/Ext/Form.xml:86; src_ext/InformationRegisters/УЗ_Настройки.xml:192; src_ext/InformationRegisters/УЗ_Настройки.xml:231; src_ext/Documents/УЗ_Урок/Ext/ManagerModule.bsl:177 -->
