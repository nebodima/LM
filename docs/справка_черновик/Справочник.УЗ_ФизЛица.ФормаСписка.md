## Кнопки и действия

- [уточнить] подпись стандартной кнопки — открывает создание новой карточки. <!-- src: src_ext/Catalogs/УЗ_ФизЛица/Forms/ФормаСписка/Ext/Form.xml:5 -->

- [уточнить] подпись стандартной кнопки — открывает создание группы справочника. <!-- src: src_ext/Catalogs/УЗ_ФизЛица/Forms/ФормаСписка/Ext/Form.xml:12 -->

- [уточнить] подпись стандартной кнопки — создаёт копию выбранной записи. <!-- src: src_ext/Catalogs/УЗ_ФизЛица/Forms/ФормаСписка/Ext/Form.xml:19 -->

- «Напомнить» — открывает новую запись напоминания по выбранному человеку. <!-- src: src_ext/Catalogs/УЗ_ФизЛица/Forms/ФормаСписка/Ext/Form.xml:25; src_ext/CommonCommands/УЗ_Напомнить.xml:4; src_ext/CommonCommands/УЗ_Напомнить/Ext/CommandModule.bsl:6; src_ext/CommonModules/УЗ_ОповещенияКлиент/Ext/Module.bsl:28 -->

- [уточнить] подпись кнопки для документа «Списания/оприходования остатков» — открывает создание документа «Списания/оприходования остатков» на основании родительской записи выбранной строки; [уточнить] соответствует ли эта привязка назначению команды. <!-- src: src_ext/Catalogs/УЗ_ФизЛица/Forms/ФормаСписка/Ext/Form.xml:46; src_ext/Documents/УЗ_СписаниеОстатков.xml:26 -->

- [уточнить] подпись кнопки для документа «Приход денег (ПКО)» — открывает создание документа «Приход денег (ПКО)» на основании текущей записи. <!-- src: src_ext/Catalogs/УЗ_ФизЛица/Forms/ФормаСписка/Ext/Form.xml:58; src_ext/Documents/УЗ_ПриходДенег.xml:26 -->

- [уточнить] подпись кнопки для документа «Расход денег (РКО)» — открывает создание документа «Расход денег (РКО)» на основании текущей записи. <!-- src: src_ext/Catalogs/УЗ_ФизЛица/Forms/ФормаСписка/Ext/Form.xml:69; src_ext/Documents/УЗ_РасходДенег.xml:26 -->

## Результат

Форма показывает записи справочника; дальнейшее действие определяется выбранной командой из раздела выше. <!-- src: src_ext/Catalogs/УЗ_ФизЛица/Forms/ФормаСписка/Ext/Form.xml:94 -->
