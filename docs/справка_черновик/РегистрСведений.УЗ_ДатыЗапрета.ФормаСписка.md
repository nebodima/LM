# Даты запрета изменения — список

Форма показывает правила, ограничивающие изменение и удаление документов студии за прошлые даты. Есть общее правило и отдельные правила пользователей. <!-- src: src_ext/InformationRegisters/УЗ_ДатыЗапрета/Forms/ФормаСписка/Ext/Form.xml:9; src_ext/InformationRegisters/УЗ_ДатыЗапрета/Forms/ФормаСписка/Ext/Form.xml:92 -->

## Поля и порядок работы

- «Пользователь»: пустое значение означает общее правило; отдельная строка пользователя имеет приоритет перед общим правилом. <!-- src: src_ext/InformationRegisters/УЗ_ДатыЗапрета/Forms/ФормаСписка/Ext/Form.xml:65; src_ext/InformationRegisters/УЗ_ДатыЗапрета/Forms/ФормаСписка/Ext/Form.xml:9; src_ext/InformationRegisters/УЗ_ДатыЗапрета.xml:176 -->
- «Дата запрета»: документы с этой датой и раньше нельзя изменять и удалять. <!-- src: src_ext/InformationRegisters/УЗ_ДатыЗапрета/Forms/ФормаСписка/Ext/Form.xml:70; src_ext/InformationRegisters/УЗ_ДатыЗапрета/Forms/ФормаСписка/Ext/Form.xml:9; src_ext/InformationRegisters/УЗ_ДатыЗапрета.xml:80; src_ext/CommonModules/УЗ_ДатыЗапрета/Ext/Module.bsl:48 -->
- «Запрет старше, дней»: число дней для скользящей границы; на администратора эта граница не действует. При двух границах применяется более поздняя. <!-- src: src_ext/InformationRegisters/УЗ_ДатыЗапрета/Forms/ФормаСписка/Ext/Form.xml:75; src_ext/InformationRegisters/УЗ_ДатыЗапрета.xml:127; src_ext/CommonModules/УЗ_ДатыЗапрета/Ext/Module.bsl:28 -->

Сначала определите, для кого нужно правило, затем фиксированную дату и/или число дней. ## Результат и сообщения

Правило проверяется при записи и удалении документов. Перенос существующего документа на более позднюю дату не обходит запрет: учитывается также его прежняя дата. <!-- src: src_ext/CommonModules/УЗ_ДатыЗапрета/Ext/Module.bsl:54; src_ext/CommonModules/УЗ_ДатыЗапрета/Ext/Module.bsl:72; src_ext/CommonModules/УЗ_ДатыЗапрета/Ext/Module.bsl:86 -->

При попытке изменить закрытый документ выводится сообщение «Документ от … в закрытом периоде: изменять и удалять документы по … включительно запрещено (Настройки → Даты запрета изменения).» Даты подставляются из документа и правила. <!-- src: src_ext/CommonModules/УЗ_ДатыЗапрета/Ext/Module.bsl:66 -->
