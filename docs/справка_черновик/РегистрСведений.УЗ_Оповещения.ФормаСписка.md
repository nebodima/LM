# Мои оповещения — список

Форма показывает ваши личные и общие оповещения. По умолчанию завершённые записи скрыты; список упорядочивается по сроку от позднего к раннему. <!-- src: src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form/Module.bsl:7; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form/Module.bsl:20; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form/Module.bsl:37 -->

## Поля и порядок работы

Просмотрите колонки «Срок», «Описание», «Источник», «Пользователь», «Завершено» и «Создано», чтобы найти нужное напоминание. «Создано» показывает сохранённое время события. <!-- src: src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:77; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:78; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:79; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:80; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:81; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:82; src_ext/InformationRegisters/УЗ_Оповещения.xml:332 -->

«Показывать завершённые» включает завершённые записи в список или снова скрывает их. Отбор по текущему пользователю и общим оповещениям при этом сохраняется. <!-- src: src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:16; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:115; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form/Module.bsl:7; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form/Module.bsl:30; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form/Module.bsl:37 -->

## Кнопки и результат

Выделите нужные строки и нажмите «Завершить». Существующие незавершённые оповещения получают отметку выполнения, после чего список обновляется. Без выбранных строк действие завершается без сообщения. <!-- src: src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:5; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:123; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form/Module.bsl:56; src_ext/CommonModules/УЗ_Сервер/Ext/Module.bsl:214 -->

Содержимое напоминаний сохраняется при завершении. Записи уже завершённых или исчезнувших оповещений пропускаются. <!-- src: src_ext/CommonModules/УЗ_Сервер/Ext/Module.bsl:220 -->

## Сообщения

У команды «Завершить» нет собственного текста успешного завершения или ошибки; исключение при записи передаётся дальше после отмены изменения текущего оповещения. <!-- src: src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form.xml:123; src_ext/InformationRegisters/УЗ_Оповещения/Forms/ФормаСписка/Ext/Form/Module.bsl:56; src_ext/CommonModules/УЗ_Сервер/Ext/Module.bsl:225 -->
