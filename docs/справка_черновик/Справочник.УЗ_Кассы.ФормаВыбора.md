## Порядок работы

Сначала найдите нужную строку по данным в таблице, затем используйте доступную команду. Состав колонок приведён ниже. <!-- src: src_ext/Catalogs/УЗ_Кассы/Forms/ФормаВыбора/Ext/Form.xml:47 -->

## Кнопки и действия

- [уточнить] подпись стандартной кнопки — открывает создание новой карточки. <!-- src: src_ext/Catalogs/УЗ_Кассы/Forms/ФормаВыбора/Ext/Form.xml:6 -->

- [уточнить] подпись стандартной кнопки — открывает создание группы справочника. <!-- src: src_ext/Catalogs/УЗ_Кассы/Forms/ФормаВыбора/Ext/Form.xml:13 -->

- [уточнить] подпись стандартной кнопки — создаёт копию выбранной записи. <!-- src: src_ext/Catalogs/УЗ_Кассы/Forms/ФормаВыбора/Ext/Form.xml:20 -->

- «Сделать основной» — назначает выбранную кассу основной, снимает этот признак с найденной прежней основной кассы и обновляет список. <!-- src: src_ext/Catalogs/УЗ_Кассы/Forms/ФормаВыбора/Ext/Form.xml:26; src_ext/Catalogs/УЗ_Кассы/Forms/ФормаВыбора/Ext/Form.xml:189; src_ext/Catalogs/УЗ_Кассы/Forms/ФормаВыбора/Ext/Form/Module.bsl:9 -->

## Результат

Форма показывает записи справочника; дальнейшее действие определяется выбранной командой из раздела выше. <!-- src: src_ext/Catalogs/УЗ_Кассы/Forms/ФормаВыбора/Ext/Form.xml:47 -->
