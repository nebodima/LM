# Помещения — список

Помогает найти нужную запись и просмотреть её данные в справочнике «Помещения». <!-- src: src_ext/Catalogs/УЗ_Помещения.xml:26; src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:37 -->

## Порядок работы

Сначала найдите нужную строку по данным в таблице, затем используйте доступную команду. Состав колонок приведён ниже. <!-- src: src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:37 -->

## Поля и сведения на форме

| Подпись | Где смотреть или заполнять |
|---|---|
| Цвет для отображения | Колонка таблицы. <!-- src: src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:108; src_ext/Catalogs/УЗ_Помещения.xml:101 --> |
| Не контролировать пересечения | Колонка таблицы. <!-- src: src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:114; src_ext/Catalogs/УЗ_Помещения.xml:189 --> |
| Комментарий | Пояснение к записи. <!-- src: src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:120; src_ext/Catalogs/УЗ_Помещения.xml:145 --> |

[уточнить] Точные подписи части полей не заданы заголовком или синонимом в доступных исходниках: название записи, код записи. В черновике им не присвоены вымышленные названия. <!-- src: src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:96; src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:102 -->

## Кнопки и действия

- [уточнить] подпись стандартной кнопки — открывает создание новой карточки. <!-- src: src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:5 -->

- [уточнить] подпись стандартной кнопки — открывает создание группы справочника. <!-- src: src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:11 -->

- [уточнить] подпись стандартной кнопки — создаёт копию выбранной записи. <!-- src: src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:16 -->

«Не контролировать пересечения» исключает это помещение из проверки совпадающего времени уроков. Проверка занятости педагога от этой отметки не зависит. <!-- src: src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:114; src_ext/Catalogs/УЗ_Помещения.xml:189; src_ext/Documents/УЗ_Урок/Ext/ManagerModule.bsl:296 -->

## Результат

Форма показывает записи справочника; дальнейшее действие определяется выбранной командой из раздела выше. <!-- src: src_ext/Catalogs/УЗ_Помещения/Forms/ФормаСписка/Ext/Form.xml:37 -->
