# Печатная форма

Форма показывает подготовленный печатный документ и позволяет отправить его на печать. Содержимое формируется при открытии по переданному документу и макету. <!-- src: src_ext/CommonForms/УЗ_ПечатнаяФорма/Ext/Form/Module.bsl:11; src_ext/CommonForms/УЗ_ПечатнаяФорма/Ext/Form.xml:19 -->

## Порядок работы

Проверьте подготовленный документ. Он открывается только для просмотра, без сетки и заголовков строк и колонок; вводить данные здесь не требуется. <!-- src: src_ext/CommonForms/УЗ_ПечатнаяФорма/Ext/Form/Module.bsl:12 -->

«Печать» открывает диалог печати подготовленного документа. Других явно размещённых кнопок в этой форме нет. <!-- src: src_ext/CommonForms/УЗ_ПечатнаяФорма/Ext/Form.xml:5; src_ext/CommonForms/УЗ_ПечатнаяФорма/Ext/Form.xml:43; src_ext/CommonForms/УЗ_ПечатнаяФорма/Ext/Form/Module.bsl:23 -->

## Результат и сообщения

Действие формы — вывод печатного документа; запись или проведение исходного документа в её обработчике не вызываются. <!-- src: src_ext/CommonForms/УЗ_ПечатнаяФорма/Ext/Form/Module.bsl:23 -->

Если не передан источник формирования, открытие отменяется без отдельного сообщения. [уточнить] Пользовательский текст для такого случая в модуле не задан. <!-- src: src_ext/CommonForms/УЗ_ПечатнаяФорма/Ext/Form/Module.bsl:7 -->
