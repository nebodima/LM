# Абонемент — выбор

Помогает выбрать нужную запись в справочнике «Абонемент». <!-- src: src_ext/Catalogs/УЗ_Абонемент.xml:26; src_ext/Catalogs/УЗ_Абонемент/Forms/ФормаВыбора/Ext/Form.xml:18 -->

## Порядок работы

Сначала найдите нужную строку по данным в таблице, затем используйте доступную команду. Состав колонок приведён ниже. <!-- src: src_ext/Catalogs/УЗ_Абонемент/Forms/ФормаВыбора/Ext/Form.xml:18 -->

| Активный | Колонка таблицы. <!-- src: src_ext/Catalogs/УЗ_Абонемент/Forms/ФормаВыбора/Ext/Form.xml:107; src_ext/Catalogs/УЗ_Абонемент.xml:267 --> |

## Кнопки и действия

[уточнить] Состав и подписи автоматически добавляемых команд. Отдельные кнопки в разметке этой формы не заданы. <!-- src: src_ext/Catalogs/УЗ_Абонемент/Forms/ФормаВыбора/Ext/Form.xml:4 -->

## Результат

Форма показывает записи справочника; дальнейшее действие определяется выбранной командой из раздела выше. <!-- src: src_ext/Catalogs/УЗ_Абонемент/Forms/ФормаВыбора/Ext/Form.xml:18 -->
