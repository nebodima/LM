- [уточнить] подпись стандартной кнопки — открывает создание новой карточки. <!-- src: src_ext/Catalogs/УЗ_Фото/Forms/ФормаВыбора/Ext/Form.xml:6 -->

## Результат

Форма показывает записи справочника; дальнейшее действие определяется выбранной командой из раздела выше. <!-- src: src_ext/Catalogs/УЗ_Фото/Forms/ФормаВыбора/Ext/Form.xml:40 -->

При переходе на другую строку справа обновляется изображение выбранной записи. <!-- src: src_ext/Catalogs/УЗ_Фото/Forms/ФормаВыбора/Ext/Form.xml:120; src_ext/Catalogs/УЗ_Фото/Forms/ФормаВыбора/Ext/Form/Module.bsl:3; src_ext/Catalogs/УЗ_Фото/Forms/ФормаВыбора/Ext/Form/Module.bsl:7 -->
