# Цена тарифа — форма из карточки тарифа

Форма задаёт цену тарифа на дату: общую сумму и количество часов либо уроков, за которые она взимается. ## Что заполнить

1. Укажите «Дата» и «Тариф». Для тарифа включена проверка заполнения. <!-- src: src_ext/InformationRegisters/УЗ_ЦеныТарифов/Forms/ФормаЗаписиТолькоЧтение/Ext/Form.xml:11; src_ext/InformationRegisters/УЗ_ЦеныТарифов/Forms/ФормаЗаписиТолькоЧтение/Ext/Form.xml:22; src_ext/InformationRegisters/УЗ_ЦеныТарифов.xml:318; src_ext/InformationRegisters/УЗ_ЦеныТарифов.xml:340 -->
2. Заполните либо «Кол-во часов», либо «Кол-во уроков». Изменение часов обнуляет число уроков, изменение уроков обнуляет часы. <!-- src: src_ext/InformationRegisters/УЗ_ЦеныТарифов/Forms/ФормаЗаписиТолькоЧтение/Ext/Form.xml:27; src_ext/InformationRegisters/УЗ_ЦеныТарифов/Forms/ФормаЗаписиТолькоЧтение/Ext/Form.xml:37; src_ext/InformationRegisters/УЗ_ЦеныТарифов.xml:230; src_ext/InformationRegisters/УЗ_ЦеныТарифов.xml:274; src_ext/InformationRegisters/УЗ_ЦеныТарифов/Forms/ФормаЗаписиТолькоЧтение/Ext/Form/Module.bsl:13; src_ext/InformationRegisters/УЗ_ЦеныТарифов/Forms/ФормаЗаписиТолькоЧтение/Ext/Form/Module.bsl:19 -->
3. Введите «Сумма за все часы/уроки». Для неё включена проверка заполнения. Подсказка рядом делит сумму на положительное число уроков или часов и показывает цену единицы с двумя знаками после запятой. <!-- src: src_ext/InformationRegisters/УЗ_ЦеныТарифов/Forms/ФормаЗаписиТолькоЧтение/Ext/Form.xml:53; src_ext/InformationRegisters/УЗ_ЦеныТарифов/Forms/ФормаЗаписиТолькоЧтение/Ext/Form.xml:62; src_ext/InformationRegisters/УЗ_ЦеныТарифов.xml:186; src_ext/InformationRegisters/УЗ_ЦеныТарифов.xml:213; src_ext/InformationRegisters/УЗ_ЦеныТарифов/Forms/ФормаЗаписиТолькоЧтение/Ext/Form/Module.bsl:27 -->
