- [уточнить] подпись стандартной кнопки — открывает создание новой карточки. <!-- src: src_ext/Catalogs/УЗ_ДисконтныеКарты/Forms/ФормаСписка/Ext/Form.xml:5 -->

- [уточнить] подпись стандартной кнопки — создаёт копию выбранной записи. <!-- src: src_ext/Catalogs/УЗ_ДисконтныеКарты/Forms/ФормаСписка/Ext/Form.xml:12 -->

- [уточнить] подпись стандартной кнопки — открывает создание группы справочника. <!-- src: src_ext/Catalogs/УЗ_ДисконтныеКарты/Forms/ФормаСписка/Ext/Form.xml:18 -->

- «Отчет по дисконтным картам» — открывает отчёт по дисконтным картам; значение отбора клиента берётся из первого элемента отбора текущего списка. <!-- src: src_ext/Catalogs/УЗ_ДисконтныеКарты/Forms/ФормаСписка/Ext/Form.xml:25; src_ext/Catalogs/УЗ_ДисконтныеКарты/Forms/ФормаСписка/Ext/Form.xml:229; src_ext/Catalogs/УЗ_ДисконтныеКарты/Forms/ФормаСписка/Ext/Form/Module.bsl:3 -->
