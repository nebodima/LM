# Список отчётов

Здесь собраны доступные вам отчёты раздела отчётов студии. Отчёты, на использование которых нет права, пропускаются; список сортируется по названию. <!-- src: src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form/Module.bsl:9; src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form/Module.bsl:14; src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form/Module.bsl:22 -->

## Как открыть отчёт

Найдите нужную строку по колонкам «Отчет» и «Пояснение», затем нажмите «Открыть» или выберите строку списка. Оба действия открывают форму выбранного отчёта. <!-- src: src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form.xml:62; src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form.xml:68; src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form.xml:99; src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form.xml:114; src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form.xml:8; src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form.xml:133; src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form/Module.bsl:31; src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form/Module.bsl:43; src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form/Module.bsl:60 -->

## Результат и сообщения

Открывается выбранный отчёт. Если текущая строка отсутствует, действие завершается без сообщения; создавать записи студии или менять её расчёты этот обработчик не вызывает. <!-- src: src_ext/CommonForms/УЗ_СписокОтчетов/Ext/Form/Module.bsl:54 -->
