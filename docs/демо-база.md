## Кому можно отдавать .dt — важно

В выгрузке `.dt` — **вся база, включая конфигурацию УНФ фирмы «1С»**. Лицензия 1С запрещает распространять её
программы и их компоненты ([юридические-правила.md](юридические-правила.md), раздел 2). Поэтому:

- `.dt` **не выкладывать** на Инфостарт, сайт, облако с открытой ссылкой и **не отправлять покупателям**;
- использовать для себя: показ по видеосвязи, снимки и видео, восстановление витрины, проверка обновления
  расширения на заполненной базе;
- покупатель получает только `.cfe` и ставит его в свою базу (УНФ/БП/УТ по своей лицензии); наполнить свою базу для
  знакомства ему помогает помощник первой настройки (7 шагов). Отдельная обработка демо-наполнения для покупателя —
  кандидат этапа 2.1 ([состояние-работ.md](состояние-работ.md)).
- Публичный веб-стенд на копии УНФ — не поднимать до ответа юриста (там же, раздел 2).

## Выгрузка .dt

    python tools\демо\выгрузить_dt.py

Скрипт никогда не выгружает базу владельца напрямую:

1. проверяет, что `UZ_DEMO` никем не открыта (файл `1Cv8.1CD` открывается монопольно) — иначе СТОП: владелец
   должен выйти, веб-стенд 8095 (`httpd_uz`) — остановлен;
2. копирует `1Cv8.1CD` в `C:\1c_bases\UZ_DEMO_DT` (1 с на 2,7 ГБ);
3. в копии зачищает секреты: настройки почты «Учёта занятий» (`УЗ_НастройкиПочты` — сервер, логин, пароль SMTP),
   журнал рассылки, безопасное хранилище хозяина (пароли учётных записей почты и интернет-сервисов БСП), пароли
   пользователей ИБ; удаляет чужие расширения (в копии владельца стоит выключенный `ПЛ_ext` — его код попал бы в
   `.dt`); проверяет, что у физлиц продукта только вымышленные контакты;
4. выгружает копию пакетным конфигуратором `/DumpIB`; файл больше 50 МБ в git не кладётся —
   он переносится в `C:\1c_bases\выпуск\`, в `releases/демо/` лежит только README.

## Что показывать (сценарий знакомства)

1. Раздел «Учёт занятий»: журнал уроков, календарь недели по педагогам и помещениям.
2. Урок группы: явка, «К оплате», абонемент ученика — цена урока = цена абонемента / занятия.
3. Панель ученика: сводка по предметам, остаток абонемента, долг, продление.
4. Приход денег на основании абонемента, печать ПКО; взаиморасчёты с учениками, два должника, рассылка должникам.
5. Расчёт зарплаты за прошлый месяц и выплата; «Мои уроки» педагога.
6. Отчёты: аналитика по ученикам, ведомость по кассе, явки.
