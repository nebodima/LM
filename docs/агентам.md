# Памятка агенту (читать вместо всей документации)

Продукт — расширение 1С `УЗ_ext` «Учёт занятий» для УНФ 3.0 / БП 3.0 / УТ 11.5. Исходники — `src_ext/`.
Ветка `uz-ext`, **основная папка, без worktree**. Коммитить только свои файлы: `git add <пути>` + `git commit -- <пути>`.
Не пушить. Codex — только если в задании сказано.

## Прочитать
1. `CLAUDE.md` (правила, 2 минуты).
2. Только те документы, которые названы в задании. Остальное — поиском (Grep) по месту, а не целиком.
   Решения по учёту — `docs/аудит_полный_2026-09-28.md` раздел 7 (искать номер «В<число>», не читать весь файл).

## Команды
| Что | Команда | Время |
|---|---|---|
| правка → база → тест | `python tools\итерация.py --база=<своя копия> --тест=<имя>` (`--модули` для форм) — из PowerShell | 12–20 с |
| аудиты | `python tools\аудиты\все_аудиты.py` | ~5 с |
| самотест аудитов (если правил аудиты) | `python tools\аудиты\самотест.py` | ~7 с |
| **финал одной командой** | `pwsh -File tools\финал.ps1 -База <своя копия> [-Сценарии] [-БезДеплоя]` — аудиты → деплой → прогон → сценарии, один итог | 3–5 мин |
| формат BSL | `python tools\формат_bsl.py` | 1 с |

Сначала весь код, потом **один** `финал.ps1`. Красное — чинить и повторять упавший тест итерацией, потом финал ещё раз.

## Базы и лимиты
- Платформа 8.3 (по умолчанию) и 8.5 (`-Платформа 8.5` / `--платформа=8.5`): для 8.5 — отдельная копия базы с суффиксом `85` (`C:\1c_bases\UZ_BP_Q85`), метка `.платформа` в папке базы не даёт открыть её другой линией. Подробно — `docs/проверки.md`, «Две платформы».
- Своя копия БП: скопировать `C:\1c_bases\UZ_BP_E` в `C:\1c_bases\UZ_BP_<буква>` (когда её не держит процесс 1cv8), работать там.
- Не трогать: `UZ_DEMO` (владелец), базы других агентов (названы в задании), `C:\Apache24`, чужие процессы 1cv8, кластер 1С.
- Лицензий 1С мало: **не больше 2 своих сеансов**; «нет свободной лицензии» — ждать 1–2 мин, до 3 раз.
- Тест дольше 10 с — дефект, разобрать. Каждый шаг замерять.
- Пароли и токены — только из переменных среды пользователя (`UZ_SQL_*`, `UZ_TELEGRAM_TOKEN`), никуда не записывать.

## Обязательное в конце
- Новый тест хоть раз красный на сломанном коде; новый аудит — мутация в `самотест.py`.
- Строка в `docs/проверки.md` на каждый новый тест/аудит; справка F1 затронутых форм; `docs/журнал-изменений.md` если меняется поведение.
- Отчёт: кратко по-русски — что сделано, решения (номера В), результат `финал.ps1` с временем.

## Ожидания
- Никаких циклов «until … sleep» без предела времени. Ждать фоновую команду — только с таймаутом (не больше 10 мин) и с выходом по нему; перед отчётом убедиться, что своих фоновых ожиданий и процессов не осталось (они висят часами после конца агента).
- Веб-стенд: каждая загрузка веб-клиента оставляет сеанс, который держит лицензию 1С до таймаута. Перед каждым проходом (снимки, запись, обход) — перезапуск своего Apache (`tools\видео\стенд.py --старт` перезапускает сам), после работы — `--стоп`. Один проход — одна вкладка, не открывать клиента заново на каждую форму.
