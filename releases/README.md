## Правила

1. **Имя** — `УЗ_ext_<версия>.cfe`, версия — ровно `<Version>` из `src_ext/Configuration.xml`.
2. **Подняли версию** — блок в `docs/журнал-изменений.md` (аудит `журнал_изменений`), новый файл сюда, строка в
   таблицу выше. Старые выпуски не перезаписывать: покупатель может прислать вопрос по любой версии.
3. **Собирать только из зелёного состояния:** все аудиты 0, самотест без промахов, деплой в копию БП и полный прогон
   зелёные на том же коммите. Выгрузка — пакетным конфигуратором из базы, куда только что прошёл деплой:

       "C:\Program Files\1cv8\8.3.27.1936\bin\1cv8.exe" DESIGNER /F C:\1c_bases\UZ_BP_E /N 1 /DumpCfg C:\1c_bases\выпуск\УчетЗанятий_2.0.0.2.cfe -Extension УЗ_ext /DisableStartupDialogs /Out C:\1c_bases\выпуск\dump.log

   Журнал `dump.log` — «Сохранение конфигурации успешно завершено»; затем копия сюда под именем по правилу 1.
4. **Черновые и промежуточные** сборки (для проверки у владельца, «fix», «v2») — в `archive/`, в таблицу не
   попадают и покупателям не отдаются.
5. **Что сюда нельзя:** `.dt` и `.cf` типовых конфигураций (УНФ/БП/УТ — собственность 1С, см.
   `docs/юридические-правила.md`), файлы больше 50 МБ (они — в `C:\1c_bases\выпуск\`, здесь только описание),
   пароли и настройки почты.
6. Файл `.cfe` в git — допустимо (1,6 МБ); демо-база — см. `демо/README.md`.
